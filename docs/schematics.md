# Структурные схемы СОТ и СПС

Кнопки «Структурная схема» на панелях **SOT** (охранное телевидение) и
**SPS** (пожарная сигнализация) строят структурную схему на чертёжном виде по
устройствам модели и обновляют её при повторных запусках. Обе работают
одинаково, у СПС дополнительно рисуются шлейфы и ответвления изоляторов.
Структурные схемы СКС и СКУД описаны отдельно —
[scs-panel.md](scs-panel.md#4-структурная-схема-buildscsschematic) и
[skud-schematic-setup.md](skud-schematic-setup.md).

> [!WARNING]
> Кнопки структурных схем тестировались мало. Все изменения откатываются
> через **Ctrl+Z**.

## Что подготовить

1. **Схемные семейства** — по условному значку на каждую категорию схемы
   («Камера», «Шкаф», «Извещатель», «Изолятор», «Панель»…), категория
   «Элементы узлов» (Detail Items).
2. **Марку узла** — тип аннотации (обычно «Обозначение, Адрес»), которая
   ставится над каждым значком.
3. **Параметры** (создать проще всего кнопкой «Параметры в ФОП», см.
   [parameters.md](parameters.md)):
   - «Помещение» — на устройствах и на схемных семействах;
   - «Адрес устройства» — на устройствах (у СОТ — и на схемных семействах);
   - служебный «Раскладка схемы» — текстовый, категория «Виды»;
   - служебный «UID устройства» — текстовый, на схемных семействах;
   - необязательные: «Уровень», «Корпус» (и у СОТ «Секция») на устройствах.
4. **Уровни** с именем вида «Этаж N» и отметкой «X,YYY» (отрицательная —
   для подземных этажей): по ним строятся подписи этажей и их порядок. Если
   в проекте уровни называются иначе, заведите параметр «Уровень» на
   устройствах с таким текстом.

## Настройки (Shift+клик)

| Поле | Что вписать |
|---|---|
| Категории устройств схемы | Логические категории по одной на строку («Камера», «Шкаф»…). Для каждой ниже выбираются схемное семейство и реальные типы устройств модели, которые к ней относятся — только они попадут на схему. |
| Категория «Шкаф» (у СПС — «Шкаф»/«Панель») | Одно имя из списка выше. К устройству этой категории рисуются линии от остальных узлов. Пусто — без линий. |
| Параметр «Помещение» и маска помещения | Если параметр на устройстве пуст, текст собирается из помещения связанной модели по маске: «Имя (Номер)» → «Офис (212)». По помещению узлы группируются в рамки. |
| Параметр «Адрес устройства» | Готовый адрес с устройства, копируется на значок; по нему же сортировка внутри помещения. |
| Параметр «Уровень» | Необязательно; пусто — уровень элемента в Revit. |
| Параметр корпуса (у СОТ — ещё и секции) | Необязательно: схема делится на блоки по корпусам (и секциям у СОТ) — у каждого свой заголовок, этажи, стояк и шкаф. |
| Значение корпуса для фильтрации | Необязательно: только этот корпус. Кнопка «Выбрать из модели…» подставит существующие значения. Чтобы вести отдельную схему на каждый корпус, задайте каждой своё имя вида. |
| Имя вида структурной схемы | Чертёжный вид создаётся при первом запуске и обновляется при повторных. |
| Смещение марки узла, мм | На сколько марка поднимается над значком. |
| Максимальная ширина строки помещений, мм | Помещения, не влезающие в строку этажа, переносятся на новую строку ниже. Пусто или 0 — одна строка на этаж. |
| Марка узла, шаблон вида | Тип марки и (необязательно) шаблон чертёжного вида — применяется на каждом запуске. |
| Служебные параметры раскладки и UID | Имена параметров из п. 3 выше. Руками не заполняются. |

Только у СПС:

| Поле | Что делает |
|---|---|
| Смещение ответвления изолятора в том же помещении, мм | Если все устройства ветки изолятора — в его же помещении, ветка рисуется под ним внутри той же рамки. Пусто — 40 мм. |
| Параметр «Имя лота» на помещении связи, фильтр «Имя лота» | Для устройств на ветках изоляторов: если у помещения связи заполнено «Имя лота» (и содержит слово фильтра), оно пишется в «Помещение» вместо имени по маске — разные помещения одного лота читаются на схеме одной рамкой. |
| Рисовать линии шлейфов и ответвлений | «нет» — только раскладка узлов, без линий (на больших моделях заметно быстрее). Верните «да», когда раскладка устроит. |
| Ставить марки узлов | «нет» — без марок (вставка марок в Revit бывает очень медленной). Марки можно добавить следующим запуском. |

## Как строится схема

- Кнопка сама находит на модели устройства выбранных типов и раскладывает их
  по этажам (сверху — с большей отметкой, подземные — внизу) и внутри этажа
  по помещениям (рамка с подписью помещения).
- **Повторный запуск** не пересоздаёт схему: раскладка прошлого запуска
  хранится в служебном параметре вида, и обновляются только этажи, помещения
  и устройства, где что-то изменилось (добавилось, пропало, переехало).
  Соседи сдвигаются, чтобы закрыть или освободить место. Значки остаются
  теми же элементами.
- **Линии к шкафу** — шинная топология: на этаже общий горизонтальный
  коллектор под узлами, короткие отводы от узлов, коллекторы выходят на
  общий стояк слева от рамок. Линии перерисовываются при каждом запуске —
  править их вручную бесполезно.

### Только СПС: шлейфы и изоляторы

- Устройства, подключённые к изолятору (по фактической цепи «изолятор →
  устройства», которую строит кнопка
  [«Цепи изолятор-устройства СПС»](fire-alarm-panels.md#3-цепи-изолятор-устройства-buildisolatorcircuitssps-только-спс)),
  рисуются отдельным рядом-веткой под изолятором, а не в своих помещениях.
- Для каждого шлейфа (адрес «панель.шлейф.номер») рисуется кольцо: внутри
  помещения — отрезок через узлы, переход в другое помещение — только через
  общий стояк слева. Кольцо идёт «туда» и «обратно» двумя проходами со
  сдвигом 3 мм. Шлейф, панель которого не попала на схему, рисуется без
  замыкания на неё.

## Порядок работы

1. Заполните на устройствах адреса (у СПС — кнопками цепей и длин шлейфов, см.
   [fire-alarm-panels.md](fire-alarm-panels.md)).
2. Shift+клик — категории схемы, семейства, типы устройств, параметры.
3. Запустите кнопку. Для больших СПС сначала — без линий и марок, потом
   включите их и запустите ещё раз.
