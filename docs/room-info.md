# Помещение из связи — требования к параметрам

Обе кнопки физически лежат на панели `Tools`: `RoomInfo` (основное
действие) и `RoomInfoSettings` (окно настроек). Какая из них видна на
ленте, определяет переключатель тем `_Themes.panel` (см.
`lib/lowlife/panel_themes.py`) — `RoomInfo` зарегистрирована в теме
`General` (вместе с остальными кнопками `Tools`/`Music`), `RoomInfoSettings`
— в теме `Settings` (вместе с кнопками `SetupParameters` остальных
дисциплин). Это общий инструмент, не привязанный к конкретной дисциплине
(СКС/СКУД/СПС/СОУЭ).

## Помещение из связи (RoomInfo)

Для каждого выбранного элемента ищет во всех подключённых связях Room, в
который попадает точка/центр этого элемента, и пишет в параметр элемента
строку `"Имя (Номер)"` (или только то, что удалось найти — имя либо номер).

Имя помещения берётся из нативного параметра Revit `Room Name` — не
настраивается. Настраиваются только два имени параметра, специфичные для
проекта:

- параметр элемента активного документа, в который пишется результат;
- параметр Room в связанной модели, откуда берётся номер помещения.

Ничего из имён параметров не хранится в репозитории — оба вводятся в окне
настроек (кнопка **Параметры помещений**, `RoomInfoSettings`) при первом
запуске и сохраняются в `%APPDATA%\pyRevit\LowLifeRoomInfo_settings.json`.

Порядок использования:

1. **Параметры помещений** (`RoomInfoSettings`) — заполнить оба имени
   параметра. Запускать один раз (или при смене проекта/ФОП).
2. Выбрать в модели элементы, которым нужно проставить помещение.
3. **Помещение из связи** (`RoomInfo`) — переносит данные, показывает
   сводку (сколько записано / не найдено / нет точки / нет параметра).

Элементы без параметра для записи или без найденного помещения не
считаются ошибкой — кнопка сообщает их количество и продолжает
обрабатывать остальные.
