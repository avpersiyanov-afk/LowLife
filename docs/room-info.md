# Помещение из связи — маска и настройки

Одна кнопка на панели `Tools` — `RoomInfo` («Помещение из связи»),
зарегистрирована в теме `General` переключателя `_Themes.panel`. Отдельной
кнопки настроек больше нет: **Shift+клик** по «Помещение из связи»
открывает окно настроек (`EXEC_PARAMS.config_mode`). Это общий инструмент,
не привязанный к дисциплине (СКС/СКУД/СПС/СОУЭ).

## Что делает (RoomInfo)

По нажатию сразу запускает выбор элементов в модели (`PickObjects` с
фильтром `lowlife.selection.pick_model_elements` — рамкой не
захватываются элементы связей, вся аннотация по `CategoryType.Annotation`,
оси, уровни, линии, опорные плоскости, помещения/зоны/площади, рамки
подрезки и виды). Предварительно выделять ничего не нужно.

Для каждого выбранного элемента ищет во всех подключённых связях Room, в
который попадает точка/центр элемента, и пишет в целевой параметр строку,
собранную **по маске** из параметров этого Room.

Поиск помещения двухпроходный: сначала точное попадание точки внутрь
Room (`Room.IsPointInRoom`), а если его нет — ближайший Room, чей контур
отстоит от точки не дальше 90 мм по горизонтали (константа
`ROOM_TOLERANCE_MM` в `lib/lowlife/room_info.py`). Второй проход
покрывает случай, когда семейство поставлено с заглублением в стену и его
точка/центр оказывается за контуром помещения на пару сантиметров.
По высоте Room во втором проходе проверяется на попадание точки в его
объём (±допуск), чтобы не подхватить помещение соседнего этажа.

## Настройки (Shift+клик)

Два поля, оба специфичны для проекта и в репозитории не хранятся —
сохраняются в `%APPDATA%\pyRevit\LowLifeRoomInfo_settings.json`:

1. **Параметр элемента** (`target_param_name`) — куда писать результат в
   активной модели. Общий параметр в ваших семействах.
2. **Маска записи параметров из смежной модели** (`room_mask`) — шаблон
   из имён параметров помещения (Room) связи, разделённых запятой и/или
   круглыми скобками. Прочий текст в маске остаётся как есть.

   | Маска | Результат |
   |---|---|
   | `Имя (Номер)` | `Офис (212)` |
   | `Имя, Номер` | `Офис, 212` |
   | `Номер` | `212` |
   | `Имя (Номер)`, номер пуст | `Офис` |

   `Имя` / `Номер` (без учёта регистра; также `Name` / `Number`) —
   псевдонимы нативных `ROOM_NAME` / `ROOM_NUMBER`. Любой другой токен
   ищется как параметр Room по имени (`get_string_param`, затем
   `LookupParameter` → `AsString`/`AsValueString`). Токен без значения
   выпадает вместе с осиротевшими скобками и запятыми (`_cleanup_mask_result`).

Значение по умолчанию маски — `Имя (Номер)` (прежний формат кнопки).

### Миграция со старого поля

Раньше вместо маски было поле `room_number_param_name` (имя параметра
номера помещения в связи), а формат был жёстко `Имя (Номер)`. При загрузке
настроек, если `room_mask` ещё не сохранена, а `room_number_param_name`
есть, маска собирается автоматически как `Имя (<старое значение>)` — вывод
не меняется. Это сделано в `load_saved_values` всех четырёх модулей
настроек (`room_info_settings`, `scs_settings`, `sot_settings`,
`fire_alarm_settings`).

## Где ещё используется маска

`room_info.find_room_value(doc, point, mask)` (поиск Room + `render_room_mask`)
заменил прежнюю пару `find_room_info` + `format_room_value`. Помимо кнопки
«Помещение из связи» его вызывают:

- структурные схемы **СКС / СОТ / СПС** — поле `room_mask` в их
  собственных настройках (`scs_settings` / `sot_settings` /
  `fire_alarm_settings`), используется, если параметр помещения на
  устройстве ещё пуст;
- **СКУД «Помещение точек прохода»** (`AssignSkudRooms` →
  `lowlife.skud_room_info`) — берёт `target_param_name` и `room_mask` из
  тех же настроек «Помещение из связи».

`find_room_param_value` (одно конкретное значение параметра Room, без
маски) оставлен как есть — им пользуется СПС для признака зоны ветки.

## Порядок использования

1. **Shift+клик** по «Помещение из связи» — заполнить параметр-приёмник и
   маску (один раз, либо при смене проекта/ФОП).
2. Нажать «Помещение из связи» — кнопка сама попросит выбрать элементы
   (рамкой и/или кликами, `Enter` — готово).
3. Кнопка переносит данные и показывает сводку (записано / не найдено /
   нет точки / нет параметра / ошибка записи).

Элементы без параметра для записи или без найденного помещения не
считаются ошибкой — кнопка сообщает их количество и продолжает
обрабатывать остальные.
