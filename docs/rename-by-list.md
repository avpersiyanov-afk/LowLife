# Переименование по списку (RenameByList)

Кнопка панели **ToolsExport**. Переименовывает выгруженные файлы по таблице «текущее имя → новое имя». Модель Revit не меняется — кнопка работает только с файлами на диске.

Типичный случай: в одной папке лежат подпапки `DWG` и `PDF` с файлами по номерам листов (`001.dwg` и `001.pdf`), и всем парам нужно дать новые имена — одним списком, а не по файлу.

## Как пользоваться

1. Нажмите кнопку и выберите папку, в которой лежат **две подпапки** с парными файлами. Если подпапок больше двух — отметьте две нужные.
2. Откроется таблица: в первом столбце — все имена файлов из обеих подпапок (без расширения), во втором впишите новое имя. Пустые и неизменённые строки пропускаются.
3. Нажмите **ОК**.

Переименовываются все файлы с таким именем (без учёта расширения) во всей выбранной папке и её подпапках — то есть и `001.dwg`, и `001.pdf` разом.

- Недопустимые в именах файлов символы кнопка не пропустит — подскажет, в каких строках они есть.
- Если файл с новым именем уже существует, этот файл пропускается — в итоговом сообщении будет, сколько таких.
