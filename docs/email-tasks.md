# Задачи из почты

Кнопка `EmailTasks` («Задачи из почты») на панели `Mail.panel` («Почта»),
зарегистрирована в теме `General` («Общее») переключателя `_Themes.panel`.
Работает без открытого проекта (`__context__ = "zero-doc"`), Revit-модель
не трогает.

Разбирает «Входящие» классического Outlook за последние N дней, отдаёт
письма ИИ — Claude или ChatGPT, способ подключения выбирается в
настройках (см. [Подключение ИИ](#подключение-ии)) — и сохраняет список
задач в Excel.

**Почта только читается**: письма не отправляются, не открываются, не
помечаются прочитанными и не перемещаются — читаются только свойства
`ReceivedTime`, `Sender*`, `To`, `CC`, `Subject`, `Body`.

## Что нужно на компьютере

- Windows, **классический** Outlook (Exchange или любой другой профиль).
  «Новый Outlook» (olk.exe) COM не поддерживает — кнопка скажет об этом.
- Excel.
- Один из способов подключения ИИ — см. [Подключение ИИ](#подключение-ии).
- Для самой кнопки ничего ставить не нужно: только stdlib IronPython и
  .NET (COM через `System.Type.GetTypeFromProgID` +
  `Activator`/`Marshal.GetActiveObject`, процесс —
  `System.Diagnostics.Process`, HTTP — `System.Net.HttpWebRequest`).

## Подключение ИИ

Способ выбирается в настройках кнопки (Shift+клик → «Подключение ИИ»);
у каждого способа там же ссылка на свой раздел этой инструкции.

| Способ | Что нужно | Как оплачивается |
|---|---|---|
| [Claude — приложение Claude Code](#claude-code-подписка-claude) | Установить Claude Code и войти в аккаунт Claude | Подписка Claude (Pro, Max, Team, Enterprise) |
| [Claude — Anthropic API](#anthropic-api-ключ) | Ключ API из консоли Anthropic | Отдельно от подписки, по объёму запросов |
| [ChatGPT — приложение Codex CLI](#codex-cli-подписка-chatgpt) | Установить Node.js и Codex CLI, войти в аккаунт ChatGPT | Подписка ChatGPT (Plus, Pro, Business, Enterprise) |
| [ChatGPT — OpenAI API](#openai-api-ключ) | Ключ API из консоли OpenAI | Отдельно от подписки, по объёму запросов |

**Приложение или ключ?** Если подписка Claude или ChatGPT уже есть —
проще приложение: платить сверх подписки не нужно, но его надо один раз
установить. Ключ API ничего ставить не требует, зато каждый запуск
стоит денег (обычно центы: несколько пачек писем по ~30 000 символов),
и баланс в консоли разработчика нужно пополнить заранее. Подписка
ChatGPT **не даёт** доступа к OpenAI API, как и подписка Claude — к
Anthropic API: это разные продукты с разной оплатой.

**Где хранится ключ.** В файле настроек
`%APPDATA%\pyRevit\LowLifeEmailTasks_settings.json` на вашем компьютере,
открытым текстом. Не пересылайте этот файл и не выкладывайте его. Можно
не вписывать ключ в настройки, а задать переменную окружения
(`ANTHROPIC_API_KEY` или `OPENAI_API_KEY`) — кнопка возьмёт её, если поле
ключа пустое:

```powershell
setx ANTHROPIC_API_KEY "sk-ant-..."
```

После `setx` перезапустите Revit — переменные окружения читаются при
запуске программы.

### Claude Code (подписка Claude)

Claude Code — программа Anthropic для командной строки. Её нужно один раз
установить и войти в свой аккаунт Claude; ключ API не нужен, запросы
идут под вашей подпиской.

1. **Подписка.** Нужен аккаунт на [claude.ai](https://claude.ai) с
   платной подпиской (Pro, Max, Team или Enterprise) — бесплатный план
   Claude Code не поддерживает.
2. **Установка.** Откройте PowerShell (Пуск → «PowerShell») и выполните:

   ```powershell
   irm https://claude.ai/install.ps1 | iex
   ```

   Программа встанет в `%USERPROFILE%\.local\bin\claude.exe` — эту папку
   кнопка находит сама. Если установщик попросит Git for Windows —
   поставьте его с [git-scm.com](https://git-scm.com/downloads/win) и
   повторите команду. Подробно — в
   [официальной инструкции](https://docs.anthropic.com/en/docs/claude-code/setup).
3. **Вход.** В новом окне PowerShell выполните `claude`. При первом
   запуске откроется браузер — войдите в свой аккаунт Claude и разрешите
   доступ. Когда в окне появится приглашение ввести запрос, вход
   выполнен; закройте окно (`/exit`).
4. **Проверка.** В PowerShell выполните:

   ```powershell
   claude -p "Ответь одним словом: работает?"
   ```

   Должен прийти короткий ответ без запроса входа.
5. **Revit.** Перезапускать Revit не нужно. Shift+клик по кнопке «Задачи
   из почты» → «Подключение ИИ»: «Claude — приложение Claude Code». Под
   полем «Путь к claude.exe» должен быть виден найденный путь. Если путь
   не найден (Claude Code стоит в другой папке), укажите полный путь к
   `claude.exe` вручную — его покажет команда `where.exe claude`.
6. **Модель** — псевдоним `sonnet` (по умолчанию), `opus` или `haiku`,
   как для `claude --model`.

Если кнопка пишет, что Claude Code не залогинен, — выполните `claude`,
затем `/login` и войдите заново. Если пишет, что версия не поддерживает
нужные флаги, — выполните `claude update`.

### Anthropic API (ключ)

1. **Аккаунт.** Откройте консоль разработчика Anthropic —
   [platform.claude.com](https://platform.claude.com) — и войдите или
   зарегистрируйтесь. Это отдельный от claude.ai кабинет, хотя войти можно
   той же почтой.
2. **Оплата.** *Settings → Billing*: пополните баланс (кредиты
   покупаются заранее). Без денег на счёте запросы отклоняются — кнопка
   скажет «закончились деньги или не подключена оплата».
3. **Ключ.** *Settings → API keys* → *Create Key*, дайте ключу понятное
   имя (например, «Revit — задачи из почты»). Скопируйте ключ (начинается
   с `sk-ant-`) — целиком он показывается только один раз.
4. **Revit.** Shift+клик по кнопке → «Подключение ИИ»: «Claude —
   Anthropic API», вставьте ключ в поле «Ключ Anthropic API», «Сохранить».
5. **Модель** — по умолчанию `claude-opus-5-5`. Можно указать полное имя
   (`claude-sonnet-5-5` — дешевле, `claude-haiku-4-5` — дешевле всех и
   быстрее) или короткое `opus` / `sonnet` / `haiku`.
6. **Проверка** — включите в настройках «Тестовый режим» и нажмите
   кнопку: она разберёт 6 выдуманных писем и должна найти 4 задачи.

Ключ можно отозвать там же, в *API keys*, — например, если он попал
к посторонним.

### Codex CLI (подписка ChatGPT)

Codex CLI — программа OpenAI для командной строки. Её нужно один раз
установить и войти в свой аккаунт ChatGPT; ключ API не нужен, запросы
идут под вашей подпиской.

1. **Подписка.** Нужен аккаунт ChatGPT с подпиской Plus, Pro, Business
   или Enterprise.
2. **Node.js.** Codex ставится через npm, поэтому сначала нужен Node.js:
   скачайте установщик LTS-версии с [nodejs.org](https://nodejs.org) и
   установите с настройками по умолчанию.
3. **Установка Codex.** В **новом** окне PowerShell выполните:

   ```powershell
   npm install -g @openai/codex
   ```

   Программа встанет в `%APPDATA%\npm\codex.cmd` — эту папку кнопка
   находит сама. Подробно — в
   [официальной инструкции](https://developers.openai.com/codex/cli).
4. **Вход.** Выполните `codex login` — откроется браузер; войдите в
   аккаунт ChatGPT («Sign in with ChatGPT») и разрешите доступ.
5. **Проверка.** В PowerShell выполните:

   ```powershell
   codex exec --skip-git-repo-check "Ответь одним словом: работает?"
   ```

   Должен прийти короткий ответ без запроса входа.
6. **Revit.** Shift+клик по кнопке → «Подключение ИИ»: «ChatGPT —
   приложение Codex CLI». Под полем «Путь к codex» должен быть виден
   найденный путь; если нет — укажите его вручную (его покажет команда
   `where.exe codex`).
7. **Модель** — пусто (по умолчанию): Codex берёт модель из своих
   настроек. Можно указать имя, как для `codex -m`.

Если кнопка пишет, что Codex не залогинен, — снова выполните
`codex login`. Если пишет, что версия не поддерживает нужные флаги, —
обновите: `npm install -g @openai/codex@latest`.

### OpenAI API (ключ)

1. **Аккаунт.** Откройте консоль разработчика OpenAI —
   [platform.openai.com](https://platform.openai.com) — и войдите или
   зарегистрируйтесь. Это отдельный от chatgpt.com кабинет.
2. **Оплата.** *Settings → Billing*: добавьте способ оплаты и пополните
   баланс. Подписка ChatGPT сюда не засчитывается.
3. **Ключ.** Страница [API keys](https://platform.openai.com/api-keys) →
   *Create new secret key*, дайте понятное имя. Скопируйте ключ
   (начинается с `sk-`) — целиком он показывается только один раз.
4. **Revit.** Shift+клик по кнопке → «Подключение ИИ»: «ChatGPT — OpenAI
   API», вставьте ключ в поле «Ключ OpenAI API», «Сохранить».
5. **Модель** — по умолчанию `gpt-5`; можно указать другую, например
   `gpt-5-mini` (дешевле).
6. **Проверка** — «Тестовый режим» в настройках, как для Anthropic API.

## Как работает

1. **Чтение почты** (`lib/lowlife/email_outlook.py`). «Входящие» (или
   подпапка из настроек) и, если включено «Включая подпапки», все
   вложенные папки. В каждой папке — только `MailItem` (`Class == 43`),
   сортировка по `ReceivedTime` по убыванию, остановка на первом письме
   старше периода; затем письма всех папок сводятся в один список по дате.
   Путь папки письма передаётся Claude вместе с письмом.
   Для Exchange-отправителей SMTP-адрес берётся через
   `Sender.GetExchangeUser().PrimarySmtpAddress` (запасные варианты —
   список рассылки и MAPI-свойства). Текст письма обрезается по маркерам
   истории переписки («От:», «From:», «-----Original Message-----»,
   «-----Исходное сообщение-----», «… пишет:», линия `____` Outlook) и до
   4000 символов (`email_tasks_core.trim_body`). Предохранитель — не
   больше 400 писем за запуск.
2. **Анализ в ИИ** (`lib/lowlife/email_ai.py` выбирает способ по ключу
   `provider`). Письма делятся на пачки ≈30 000 символов, по одному
   вызову на пачку; запрос — промпт из `prompt.txt` + сегодняшняя дата +
   письма, плюс короткий системный промпт «верни только JSON».
   - **Claude Code** (`email_claude.py`): `claude -p --output-format json
     --model <модель> --tools "" --max-turns 1 --no-session-persistence
     --strict-mcp-config --system-prompt <...>` (флаги проверены по
     `claude --help`, Claude Code 2.1). Таймаут — 3 минуты.
   - **Codex CLI** (`email_codex.py`): `codex exec --skip-git-repo-check
     --sandbox read-only --ephemeral --color never -o <файл> [-m <модель>] -`
     (флаги — по справочнику команд Codex CLI; на живом `codex` не
     проверялись). Ответ читается из файла `-o`. Системный промпт идёт
     первыми строками запроса — отдельного флага у `codex exec` нет.
     Таймаут — 5 минут.
   - **Anthropic API**: `POST https://api.anthropic.com/v1/messages`,
     заголовки `x-api-key`, `anthropic-version: 2023-06-01`; `max_tokens`
     16000, системный промпт в `system`. Для моделей с серверным запасным
     маршрутом при отказе фильтра безопасности (`claude-opus-5-5`,
     `claude-opus-5`, `claude-sonnet-5-5`, `claude-fable-5-1`) добавляются
     `fallbacks: "default"` и заголовок
     `anthropic-beta: server-side-fallback-2026-07-01`. Из ответа берутся
     блоки `text`; `stop_reason` `refusal`/`max_tokens` — ошибка пачки.
   - **OpenAI API**: `POST https://api.openai.com/v1/chat/completions`,
     `Authorization: Bearer <ключ>`, сообщения `system` + `user`; ответ —
     `choices[0].message.content`.

   У программ (Claude Code, Codex) запрос уходит **через stdin в UTF-8** —
   не аргументом (лимит длины командной строки Windows); процесс
   запускается во временной папке `%TEMP%\LowLifeEmailTasks`, чтобы не
   подхватить чужие `CLAUDE.md`/`AGENTS.md`. HTTP-запрос к API идёт в
   фоновом потоке (`email_ai_net.post_json`), таймаут — 3 минуты. Чистая
   логика (тела запросов, разбор ответов, перевод ошибок HTTP в понятный
   текст) — в `email_ai_core.py`, покрыта тестами.
3. **Разбор ответа** (`email_tasks_core.parse_tasks_json`): снимается
   ```-обёртка, из текста вытаскивается JSON `{"tasks": [...]}` (или голый
   массив). Если ответ не разобрался — он сохраняется в
   `%TEMP%\LowLifeEmailTasks\answer_*.txt`, остальные пачки
   обрабатываются дальше.
4. **Окно вывода pyRevit** — таблица задач, сортировка приоритет → срок →
   дата письма.
5. **Excel** (`lib/lowlife/email_tasks_excel.py`):
   `Документы\Задачи из почты\Задачи_ГГГГ-ММ-ДД_ЧЧММ.xlsx`, открывается
   после сохранения. Колонки: №, Задача, Кто просит, Срок, Приоритет,
   Статус (выпадающий список: Не начато / В работе / Ждёт ответа / Готово),
   Комментарий, Тема письма, Отправитель, Дата письма. Arial 10, шапка
   закреплена, автофильтр, перенос текста. Условное форматирование:
   строка со статусом «Готово» — серым; просроченный срок (и статус не
   «Готово») — красным; высокий приоритет — жёлтым.

## Промпт

Редактируется в окне настроек (Shift+клик → поле «Промпт»); один и тот
же для всех способов подключения ИИ.
Стандартный текст лежит в
`LowLife.tab/Mail.panel/EmailTasks.pushbutton/prompt.txt`. Пока текст в
настройках пустой или совпадает со стандартным, используется
`prompt.txt` — так обновления промпта в новых версиях расширения
подхватываются сами. Свой текст хранится в файле настроек (ключ
`prompt`) и при обновлении расширения не теряется; кнопка «Вернуть
стандартный промпт» подставляет текст `prompt.txt` обратно.

Сегодняшняя дата и сами письма добавляются к промпту автоматически.
Важно сохранить в промпте формат ответа
(`{"tasks":[{"email_id":…,"task":…,"requester":…,"deadline":…,
"priority":…,"comment":…}]}`) — по нему разбирается ответ.

## Настройки (Shift+клик)

`%APPDATA%\pyRevit\LowLifeEmailTasks_settings.json` (папка конфигурации
pyRevit; как и у остальных кнопок расширения — отдельный JSON-файл, а не
`pyrevit.script.get_config()`):

| Поле (ключ) | По умолчанию | Что делает |
|---|---|---|
| Подключение ИИ (`provider`) | Claude Code (`claude_cli`) | `claude_cli` / `anthropic_api` / `codex_cli` / `openai_api`, см. [Подключение ИИ](#подключение-ии) |
| Путь к claude.exe (`claude_path`) | пусто (автопоиск) | PATH → `%USERPROFILE%\.local\bin\claude.exe` → `%APPDATA%\npm\claude.cmd` |
| Модель Claude Code (`claude_cli_model`) | `sonnet` | Как для `claude --model` |
| Ключ Anthropic API (`anthropic_api_key`) | пусто (= `ANTHROPIC_API_KEY`) | Ключ `sk-ant-…` |
| Модель Anthropic API (`anthropic_api_model`) | `claude-opus-5-5` | Полное имя или `opus`/`sonnet`/`haiku` |
| Путь к codex (`codex_path`) | пусто (автопоиск) | PATH → `%APPDATA%\npm\codex.cmd` → `%USERPROFILE%\.local\bin\codex.exe` |
| Модель Codex (`codex_cli_model`) | пусто | Как для `codex -m`; пусто — из настроек Codex |
| Ключ OpenAI API (`openai_api_key`) | пусто (= `OPENAI_API_KEY`) | Ключ `sk-…` |
| Модель OpenAI API (`openai_api_model`) | `gpt-5` | Имя модели OpenAI |
| Период, дней (`days`) | 3 | Сколько последних дней разбирать |
| Только непрочитанные (`unread_only`) | нет | `Items.Restrict("[UnRead] = True")` |
| Подпапка «Входящих» (`subfolder`) | пусто | Например `Проекты/Объект 1` |
| Включая подпапки (`include_subfolders`) | да | Читать и все вложенные папки (Входящих или папки выше) |
| Тестовый режим (`test_mode`) | нет | Письма из `test_emails.json` вместо Outlook |
| Промпт (`prompt`) | пусто (= `prompt.txt`) | Свой текст промпта, см. выше |

В окне видны поля только выбранного способа подключения; при сохранении
проверяется тоже только он (программа найдена по указанному пути, ключ
есть в поле или в переменной окружения). Ключи хранятся открытым текстом
в этом файле. Модель Claude Code из старых версий (ключ `model`)
переносится в `claude_cli_model` автоматически.

## Тестовый режим

`test_emails.json` рядом со скриптом — 6 выдуманных писем: две задачи в
одном письме (с относительным сроком «до пятницы» и встречей «завтра в
10:00»), письмо с явным сроком и второй, несрочной задачей, рекламная
рассылка, «спасибо» с процитированной историей (в истории есть просьба —
она должна отрезаться), автоматическое уведомление и информационное
письмо «действий не требуется». Даты писем задаются как «сегодня минус
`days_ago`», поэтому относительные сроки всегда проверяемы.

Ожидаемый результат: 4 задачи из двух писем, рассылка/«спасибо»/
уведомление/информирование — не задачи.

## Сообщения об ошибках

- классический Outlook не найден / это «новый Outlook» без COM / Outlook не
  запущен или недоступен;
- подпапка не найдена;
- claude / codex не найден (по пути из настроек или автопоиском);
- Claude Code / Codex не залогинен; упёрся в лимит подписки; модель
  недоступна; версия программы не знает нужных флагов; таймаут;
- не указан ключ API; ключ отклонён (неверный или отозван); нет доступа;
  закончились деньги на счёте API; лимит частоты запросов; сервис
  перегружен; нет связи (интернет, прокси);
- ИИ отказался обрабатывать пачку (фильтр безопасности) или ответ
  оборвался на лимите длины — ошибка этой пачки, остальные идут дальше;
- нет писем за период;
- не удалось разобрать ответ ИИ (ответ сохраняется в файл);
- ошибка Excel.

## Известные ограничения

- Пока идёт вызов ИИ, окно прогресса обновляется через
  `Application.DoEvents()` (иначе оно «замерзает» на минуты и «Отмена» не
  работает).
