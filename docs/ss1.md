# СС1-8Mile — расстановка оборудования сетей связи

Кнопка «СС1-8Mile» (панель **SS1**) за один запуск на отмеченных уровнях:

1. **Кроссы** — по два в каждой шахте СС на каждом уровне, через который
   шахта проходит: в центре шахты, на заданных высотах, повёрнуты по шахте.
   В параметр «Помещение» пишется текст из настроек (по умолчанию «Ниша СС»).
2. **Кабельные подводы** — у двери из прихожей квартиры в коридор/вестибюль
   (по связи АР), на грани стены со стороны квартиры, лицом в прихожую. У
   двухуровневой квартиры (одно имя лота на разных уровнях) — только в
   нижней прихожей. В «Помещение» пишется имя лота.
3. **Цепи** — от кросса №1 шахты СС своей секции на том же уровне к каждому
   подводу (если параметры секции не заданы — от ближайшей шахты уровня).
4. **Заполнение LOI** — кроссам и подводам копируются параметры «Форм» по
   настройкам кнопки «Заполнение LOI» (см. [loi-panel.md](loi-panel.md)).
5. **Маркировка подводов** (адрес устройства) по маске.

Перед расстановкой все экземпляры выбранных типов кросса и подвода на
отмеченных уровнях удаляются. Всё — одна транзакция, **Ctrl+Z** откатывает
целиком.

## Что подготовить

- **Шахты СС** — экземпляры «Обобщённой модели» одного семейства, у типа или
  экземпляра которых отмечена галочка (параметр Да/Нет) «СС»; у шахт других
  систем отмечены другие галочки.
- **Семейства кросса и подвода**, загруженные в проект.
- **Связь АР** с помещениями «Прихожая», «Коридор»/«Вестибюль» и дверями между
  ними; у помещений квартир — «Имя лота», при нескольких секциях — «Номер
  секции».
- **Параметры на оборудовании**: «Помещение» и «Адрес устройства» — создать
  проще всего кнопкой «Параметры в ФОП» (система «СС1», см.
  [parameters.md](parameters.md)).

## Настройки (Shift+клик)

Главное окно (выпадающие списки по загруженным семействам, у каждого — поиск
по части имени):

- **Шахта СС** — семейство «Обобщённой модели» → галочка (параметр Да/Нет,
  «СС» выбирается сама, если есть).
- **Кросс** и **кабельный подвод** — семейство → тип.
- **Тип электрической цепи** — по умолчанию Data (данные).

Остальные поля:

| Поле | Что вписать |
|---|---|
| Помещение квартиры, где ставится подвод | По умолчанию «Прихожая». |
| Соседние помещения | Через запятую, по умолчанию «Коридор, Вестибюль» — подвод ставится у двери в одно из них. |
| Параметр помещения «Имя лота» | В связи АР. Значение пишется в подвод; по нему же находятся двухуровневые квартиры. |
| Параметр помещения «Номер секции» и параметр шахты «Номер секции» | Цепь строится от кросса №1 шахты той же секции. Оба пусты — от ближайшей шахты уровня. |
| Параметр экземпляра «Помещение» | Кроссам пишется текст ниже, подводам — имя лота. Пусто — не пишется. |
| Текст для кроссов | По умолчанию «Ниша СС». |
| Высоты, мм | Кросс №1 (1000), кросс №2 (1500), подвод (2700 — значение по умолчанию в окне запуска). |
| Отступ подвода от грани стены | Внутрь прихожей; 0 — точно на грани. |
| Допуск по высоте при сопоставлении уровней, мм | Уровень двери связи совпадает с уровнем модели, если отметки отличаются не больше; тот же допуск — для проверки, проходит ли шахта через уровень. |
| Параметр маркировки подвода | Параметр «Адрес устройства» подвода. Пусто — маркировка не заполняется. |
| Маска маркировки | Буквы заменяются значениями своих параметров, остальное остаётся как есть: «A.B.C» → «3.1.45». Параметр для каждой буквы — строка «A=Этаж; B=Секция; C=Номер квартиры». Буквы можно набирать по-русски (А = A). Значения берутся у подвода (после LOI), иначе у прихожей в связи. |

## Отчёт

Что поставлено (кроссы, подводы, цепи) и предупреждения: «ВНИМАНИЕ» по прихожим без имени лота (подвод ставится в каждую такую), по
дверям, где не удалось определить сторону квартиры, и по элементам, не
попавшим ни в одну «Форму» LOI.
