# Параметры, с которыми работает LowLife

Здесь перечислены параметры, которые нужно создать в проекте, чтобы работали
кнопки LowLife.

**Имена параметров берите в соответствии с вашим ФОП.** В столбце «Пример
имени» показано, как параметр может называться (`LL_` — условный префикс
проекта). Если в вашем ФОП уже есть подходящий по смыслу параметр, создавать
новый не нужно — используйте его.

## Как подготовить проект

1. Найдите в своём ФОП параметры из таблицы ниже, а недостающие добавьте в
   ФОП (тип данных — по столбцу «Данные»).
2. В Revit: **Управление → Параметры проекта → Добавить → Общий параметр**,
   выберите параметр, укажите «Экземпляр» или «Тип» (столбец «Экз./Тип») и
   отметьте галочками категории из первого столбца.
3. Shift+клик по кнопке LowLife откроет её настройки — впишите туда имена
   ваших параметров. Поле узнаётся по смыслу из примера имени: для
   `LL_Адрес_узла` это поле «[Адресация] Параметр «Адрес узла»», для
   `LL_Длина_в_лотке` — «Параметр цепи «Длина проводника в лотке»».

Если параметр нужен нескольким дисциплинам (например, «Адрес устройства»),
создайте **один** параметр и впишите его имя в настройки каждой дисциплины.

Для СКС и СКУД значительную часть шагов 1–2 делает кнопка «Привязка
параметров» на их панелях: она привязывает к категориям параметры, которые уже есть
в подключённом ФОП.

Обозначения: **Экз.** — параметр экземпляра, **Тип** — параметр типа.
«Нужен для» — каким разделам нужен параметр; «Обяз.» — запустятся ли эти
кнопки без него.

## Что создавать не нужно

- **«Имя нагрузки», «Проводник», «Панель»** у электрических цепей —
  встроенные параметры Revit. В настройках просто оставьте их названия.
- **Отметка** узлов и устройств — обычно это встроенный параметр
  «Смещение» (или «Смещение от уровня»). В поле «Возможные имена параметра
  отметки» перечислите через запятую варианты, встречающиеся в ваших
  семействах.
- **«Марка» линий проводки СПС** — подойдёт встроенный параметр «Марка».
- **«Рабочий набор»** — нужен, только если в проекте имя рабочего набора
  продублировано в отдельный параметр; иначе рабочий набор определяется
  штатно.
- **Параметры камер** («Фокусное расстояние», «Дальность», «Формат
  матрицы», «Горизонтальное разрешение», «Высота установки», «Поворот
  камеры», «Наклон оптической оси вниз») — это параметры семейства камеры;
  в настройках кнопки «Зоны обзора» впишите их имена (несколько вариантов
  через `;`). Обязательны только фокусное расстояние и дальность.
- **Параметры помещений в связанной модели АР** («Имя лота», «Номер
  секции», номер помещения, параметр для группировки) — их ведёт
  архитектор; в настройках впишите, как они называются в модели АР.
- **Параметры для «Расстановки РМ, АМ, МДУ» и «Заполнения LOI»** — это
  уже существующие параметры, значения которых кнопки переносят с одного
  элемента на другой; список задаётся в настройках.
- **Признак строки справочника кабелей** — необязательный: нужен, только
  если в проекте несколько ключевых спецификаций цепей и справочник
  кабелей надо отличить от остальных.

## Что ещё нужно, кроме параметров

- **Рабочие наборы.** Кнопки отличают элементы своей дисциплины по слову в
  имени рабочего набора. Слово задаётся в настройках (Shift+клик), его можно
  поменять под свой проект:

  | Что | Поле в настройках | По умолчанию |
  |---|---|---|
  | Целевые панели СКС | «[Критерии панели] Ключевое слово рабочего набора целевых панелей» | пусто — без отбора по рабочему набору; впишите, например, «СКС» |
  | Узлы трассы СКУД | «[Узлы трассы] Ключевое слово рабочего набора элементов СКУД» | пусто — без отбора по рабочему набору; впишите, например, «СКУД» |
  | Контроллеры СКУД | «[Контроллеры] Ключевое слово рабочего набора контроллеров» | пусто — без отбора по рабочему набору; впишите, например, «СКУД» |
  | Приборы и устройства СПС / СОУЭ / СПА | «[Оборудование] Ключевое слово рабочего набора» | у СПА — «СПА», у СПС и СОУЭ пусто — без отбора по рабочему набору; впишите, например, «СПС» |
  | Кабельные лотки | «Рабочий набор» в общем окне настроек лотков (Shift+клик по любой кнопке лотка) | «КНК» |

  Узлы трассы СКС и СКУД пользуются одними и теми же параметрами —
  дисциплины разделяет рабочий набор.
- **Имена семейств и типов.** Узлы, панели, стояки, сегменты трассы,
  изоляторы СПС распознаются по слову в имени семейства или типа; слова
  тоже задаются в настройках.
- **Типы кабельных лотков** нужно создать в проекте заранее: кнопка ищет тип,
  в имени которого есть заданный текст (например `СБ_ЛЛ_1.5_СЦ`). Таблица
  имён по умолчанию для всех 20 кнопок и настройка — в
  [cable-tray-panels.md](cable-tray-panels.md).
