# Параметры, с которыми работает LowLife

Сводная таблица: какие параметры должны быть у каких типов элементов, чтобы
работали кнопки расширения. Подробности и порядок настройки — в документации
каждой панели (ссылки в конце разделов).

**Реальных имён параметров здесь нет.** Это соглашения конкретного проекта
(например, общие параметры с префиксом проекта из вашего ФОП): вы заводите
параметры с любыми именами и вписываете эти имена в окно настроек кнопки
(Shift+клик). Ниже указана **роль** параметра, то есть подпись поля в
настройках.

Обозначения:

- **Экз.** — параметр экземпляра, **Тип** — параметр типа.
- **Текст / Число / Длина / Угол** — тип данных параметра в Revit. «Число»
  у длин означает, что пишется готовое число метров без пересчёта единиц
  Revit.
- **Обяз.** — без параметра кнопка не запустится; «нет» — параметр
  необязательный (кнопка работает без него или с ограничениями).

## Соглашения, которые не являются параметрами

- Рабочие наборы: имя содержит ключевое слово дисциплины (целевые панели
  СКС, контроллеры СКУД, приборы СПС/СОУЭ/СПА, «КНК» для лотков).
- Семейства узлов, панелей, стояков, сегментов распознаются по подстроке в
  имени семейства или типа (ключевые слова задаются в настройках).
- Типы кабельных лотков должны уже быть в проекте с подстрокой вида
  `<Система>_ЛЛ_1.5_СЦ` в имени (см. [cable-tray-panels.md](cable-tray-panels.md)).
