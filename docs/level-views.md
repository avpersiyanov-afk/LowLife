# Виды по уровням

Кнопка «Виды по уровням» (панель **Tools**) создаёт планы на всех (или
выбранных) уровнях модели по отмеченным шаблонам видов — например «План
этажа СКС», «План этажа СПС» для каждого этажа за один запуск.

## Окно

- **Шаблоны видов** — список шаблонов планов проекта (этажа, потолка,
  несущих конструкций). Отметьте нужные. У каждого впишите **группы вида и
  назначения** — по одной на строке, на каждую создаётся свой вид (например
  «СКС» и «СКС_Трассы» → два плана на уровень с одним шаблоном).
- **Маска имени** — из чего собирается имя вида:

  | Подстановка | Что даёт |
  |---|---|
  | `{Уровень}` | имя уровня |
  | `{Группа вида и назначение}` | строка из списка групп шаблона |
  | `{Шаблон}` | имя шаблона вида |
  | `{Отметка}` | отметка уровня, например «+3.300» |
  | `{Этаж}`, `{Корпус}`, `{Комментарий}` | части имени уровня по шаблону имени уровня (из настроек кнопки «Секущий диапазон») |

  По умолчанию — `{Группа вида и назначение}_{Корпус}_{Этаж}_{Отметка}`.
  Внизу окна — предпросмотр имён на первом уровне; кнопка предупредит, если
  у разных видов получаются одинаковые имена.
- **«Выбирать уровни для каждого шаблона»** — после запуска для каждого
  шаблона откроется список уровней: для каких создавать его виды (выбор
  запоминается). Без галочки — все уровни.
- **«Выровнять секущий диапазон»** (по умолчанию включена) — диапазон новых
  видов выставляется как у кнопки «Секущий диапазон». Если её настройка ещё не
  заполнена, перед созданием откроется её окно. У планов потолков и видов,
  чей диапазон задаёт шаблон, диапазон не меняется — в отчёте будет пояснение.
- **«Сохранить»** — сохранить маску, группы и отметки без создания видов.
- **«Выгрузить/Загрузить настройки…»** — перенос настроек между проектами и
  компьютерами.

## Что делает

Для каждого отмеченного шаблона на каждом уровне создаётся план нужного типа
(этажа, потолка или несущих — по виду шаблона) с этим шаблоном и именем по
маске. Видимость и связи задаёт сам шаблон.

- Вид с таким же именем **на том же уровне** не создаётся заново — ему
  назначается шаблон.
- Имя, занятое видом **другого** уровня или уже выданное в этом запуске, —
  ошибка в отчёте, вид не создаётся. Поправьте маску (например, добавьте
  `{Отметка}`).

Всё одной транзакцией — **Ctrl+Z** откатывает.
