# Рабочие наборы связей

Кнопка **LowLife → Инструменты → Рабочие наборы связей** показывает загруженные
связи Revit и текущие состояния их пользовательских рабочих наборов в одном окне.
Флажок означает, что набор открыт. Можно менять несколько моделей перед нажатием
«Применить». Повторные экземпляры одной связи объединены; число в скобках —
количество экземпляров. Изменения действуют во всём текущем проекте.

Поиск находит модель или набор, включая запрос в другой раскладке.
«Открыть все» / «Закрыть все» меняют видимые наборы соответствующей модели.
Скрытые поиском флажки сохраняют выбранное состояние и тоже будут применены.
«Отмена» или закрытие окна ничего не меняют.

Изменённые связи перезагружаются из исходного источника. Это может занять время
и очищает историю отмены Revit. Файлы связанных моделей кнопка не сохраняет.
Неизменённые связи не перезагружаются. Если отдельная связь не обработана,
окно результата показывает ошибку; успешные изменения других связей остаются.

Вложенные связи доступны для просмотра: менять их загрузку следует в родительской
модели. Модели без рабочих наборов показаны с пояснением. Для связи, используемой
сразу в нескольких открытых проектах, закройте остальные проекты. Изменения
общих координат связи сначала сохраните или отмените штатными средствами Revit.

## Ручная проверка в Revit 2024

1. Подготовить тестовый проект с двумя загруженными совместными связями,
   несколькими экземплярами одной связи, открытыми и закрытыми наборами.
   Добавить модель без совместной работы и выгруженную связь.
2. Проверить, что загруженные связи перечислены, повторные экземпляры объединены,
   закрытые наборы видны со снятыми флажками, выгруженная связь не включается.
3. Изменить наборы в двух моделях, закрыть окно через «Отмена» и открыть снова:
   исходные состояния должны сохраниться.
4. Открыть один закрытый набор и закрыть один открытый в разных связях.
   Нажать «Применить», проверить геометрию на нескольких видах и экземплярах,
   затем открыть окно снова и сверить состояния с «Управление связями».
5. Проверить закрытие всех наборов и последующее открытие части наборов.
   Системные наборы не должны предлагаться для переключения.
6. Проверить поиск, включая другую раскладку, и массовые команды по результатам
   поиска. Сбросить поиск и убедиться, что прочие флажки сохранены.
7. На тестовой копии проверить отказ доступа к источнику одной связи:
   ошибка должна назвать связь, остальные изменения должны быть отражены в результате.
8. Проверить причины блокировки вложенной связи, связи в нескольких открытых
   проектах и связи с изменёнными общими координатами. Проверить RU → EN → RU.
9. Для Revit Server / облачной связи отдельно проверить перезагрузку из прежнего
   источника без изменения пути. Эти сценарии требуют соответствующего окружения.

Контракт API: [Autodesk — LoadFrom](https://help.autodesk.com/cloudhelp/2026/ENU/Revit-API-MainReference/files/html/bdb3a91e-9a0a-e68d-51da-c460535f5fd2.htm).
Реальное выполнение в Revit необходимо: тесты с подставным API проверяют логику,
но не подтверждают поведение загрузчика, облака и WPF в установленной версии.
