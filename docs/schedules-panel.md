# Панель ToolsSchedules — спецификации и Excel

Кнопки «Модель → JSON» и «JSON → модель» описаны отдельно — [docs/json-snapshot.md](json-snapshot.md). Здесь — работа со спецификациями.

## Экспорт в Эксель

Выгружает спецификацию в .xlsx, чтобы править значения в Excel. Ни Excel, ни дополнительные библиотеки не нужны.

1. Откройте спецификацию (если активна не спецификация — кнопка спросит, какую выгрузить).
2. Нажмите кнопку и укажите, куда сохранить файл.

Первый столбец — **«Revit ID»**: по нему строка файла связана с элементом модели, **не меняйте его**. Дальше — значения параметров по столбцам, как в спецификации. Выгружаются параметры экземпляров.

## Импорт из Эксель

Загружает правки из .xlsx (выгруженного кнопкой «Экспорт в Эксель») обратно в модель.

1. Нажмите кнопку и выберите файл.
2. Кнопка находит элементы по столбцу «Revit ID», параметры — по заголовкам столбцов, и записывает только изменившиеся значения.

Правила:

- **пустые ячейки пропускаются** — они не стирают значение в модели;
- пишутся только параметры экземпляров, доступные для записи; параметры типа, только для чтения и ссылки на элементы пропускаются;
- числа с единицами понимаются в текущих единицах проекта — так, как они видны в Excel.

Всё записывается одной транзакцией (откат — один **Ctrl+Z**), в конце — отчёт: сколько значений изменено, что пропущено и почему (только чтение, параметр или элемент не найден, ошибки записи).

## Разбить спецификацию

Делит спецификацию на листе на участки заданной высоты — то же, что перетаскивать ручку разделения спецификации, но сразу на нужное число частей.

1. Откройте лист и щёлкните по спецификации на нём (именно по экземпляру на листе, а не в Диспетчере проекта).
2. Нажмите кнопку и введите высоту одного участка на листе, мм (например, 180).
3. Кнопка покажет, сколько получится участков, высоту шапки и всей таблицы, и спросит подтверждение.

Первые участки получаются по заданной высоте (насколько позволяет целое число строк), последний — остаток. Шапка повторяется на каждом участке. Если спецификация уже разбита, кнопка предложит собрать её и разбить заново. Обратно в одну часть кнопка спецификацию не собирает — для этого используйте штатные средства Revit.
