# Сечение лотка (TraySection)

Кнопка панели **ToolsTraySection**. Рисует на чертёжном виде сечение кабельного лотка с фактической раскладкой кабелей и таблицу кабелей — по данным из Excel.

## Исходные данные

Файл .xlsx или .xlsm (макросы не мешают — файл читается напрямую, Excel не нужен). Данные берутся с листа **«сводные данные для плагина»** — он ищется по имени среди всех листов книги (запасной вариант — лист «Сводный»); если такого листа нет, кнопка предложит выбрать лист из списка.

Столбцы — строго по порядку:

| Столбец | Данные |
|---|---|
| A | марка кабеля |
| B | диаметр |
| C | участок (объединённые ячейки протягиваются вниз) |
| D | количество |
| F | система |
| G | % заполнения |
| H | высота лотка |
| I | ширина лотка |

## Как пользоваться

1. Откройте чертёжный вид.
2. Нажмите кнопку и выберите файл.
3. Отметьте галочками нужные участки — они построятся стопкой сверху вниз от одной точки, не внахлёст.
4. Выберите режим: **«Сечение и таблица»**, **«Только сечение»** или **«Только таблица»**. Чтобы положить сечение и таблицу на разные чертёжные виды, запустите кнопку дважды с разными режимами.
5. Если строится сечение — ответьте, показывать ли марки кабелей на кружках.
6. Укажите на виде точку вставки первого участка, остальные уйдут вниз.

## Как раскладываются кабели

Кабели укладываются от большего диаметра к меньшему: каждый — в самую низкую точку, где он касается дна, стенок или уже уложенных кабелей. Все системы вперемешку, плотно, слева направо. Кабели, которым не хватило места по высоте лотка, не пропадают молча — о них выводится отдельное предупреждение.

Контур лотка и кабели рисуются в реальном размере (масштабируются видом), а таблица и подписи — в «бумажном» размере с учётом масштаба вида, поэтому читаются одинаково при любом масштабе. Марки внутри каждого участка нумеруются с 1.
