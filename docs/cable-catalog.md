# Справочник кабелей (панель ToolsCables)

**Справочник кабелей** — ключевая спецификация категории «Электрические
цепи», на строки которой ссылается параметр цепи «Проводник». Каждая строка —
один кабель (ключевое имя + свои параметры: марка, наименование, сечение…).
Кнопки цепей LowLife (СКС, СКУД, СПС, СОУЭ, СПА, «Цепь (общее)», «Расстановка
РМ, АМ, МДУ») в настройках дают выбрать строку справочника, а при построении
пишут её в «Проводник» цепи.

## Как кнопки находят справочник

1. Берутся ключевые спецификации категории «Электрические цепи».
2. Если среди них есть спецификации с ключевым параметром «Проводник» —
   только они.
3. Если их несколько, а в настройках кнопки задан **признак строки
   справочника кабелей** (параметр, который есть только у строк нужной
   спецификации), список сужается до спецификаций с этим параметром.

Параметр цепи, в который пишется кабель, — ключевой параметр найденной
спецификации, отдельно его указывать не нужно.

## Кнопки

- **Справочник кабелей** — отчёт: все ключевые спецификации проекта (какие
  признаны справочником кабелей) и для справочника — таблица строк: ключевое
  имя, ID, столбцы спецификации и **число цепей**, где строка уже проставлена.
  Модель не меняет.
- **Правка справочника** — окно-таблица: правка значений и добавление новых
  кабелей (пустая строка внизу или «Копировать строку» — копия выбранной как
  основа). Всё записывается одной транзакцией по «Сохранить». Удалять строки
  нельзя — на них могут ссылаться цепи. Вычисляемые и только для чтения
  столбцы не редактируются. Если справочников несколько, кнопка спросит, какой
  открыть.
- **Выгрузить справочник** — в .xlsx (Excel не нужен): столбец «Ключевое имя» и
  все столбцы спецификации.
- **Загрузить справочник** — из .xlsx того же формата (первая строка —
  заголовки, обязателен столбец «Ключевое имя»). Строки сопоставляются **по
  ключевому имени**: найденные обновляются, новые добавляются, остальные
  строки проекта не трогаются. Столбцы, которых нет в спецификации проекта,
  пропускаются.

## Перенос справочника в другой проект

1. В исходном проекте — «Выгрузить справочник».
2. В новом проекте создайте ключевую спецификацию «Электрические цепи» с теми
   же полями (можно пустую) и ключевым параметром «Проводник».
3. «Загрузить справочник» — строки добавятся по ключевым именам.
