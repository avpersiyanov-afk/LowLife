# Панель ToolsFamilies — семейства из каталога

Две кнопки работают с одной **папкой-каталогом** .rfa (например, сетевой папкой с библиотекой семейств отдела). Путь к каталогу общий для обеих кнопок и запоминается; сменить его — **Shift+клик** по любой из них.

Каждое загруженное из каталога семейство получает скрытую метку с датой файла каталога. По ней «Обновление/проверка семейств» понимает, устарело ли семейство в модели.

## Загрузить семейства

Загружает выбранные семейства (или отдельные типоразмеры) из каталога в модель.

1. Нажмите кнопку (в первый раз — укажите папку-каталог).
2. Выберите разделы каталога — папки с .rfa, можно несколько. «Отмена» — все разделы.
3. В таблице отметьте нужные файлы. Столбцы: имя файла, папка, есть ли уже в модели, дата файла; таблица сортируется щелчком по заголовку.
   - **зелёным** — новые семейства;
   - **серым** — уже загруженные: они будут перезагружены.
4. Флажки внизу:
   - **«Выбрать типоразмеры»** — кнопка откроет каждый отмеченный .rfa, прочитает его типы и даст отметить нужные; загрузятся только они. Без флажка семейство грузится целиком;
   - **«Заменять значения параметров типоразмеров»** — действует только на семейства, которые уже есть в модели (то же, что выбор в штатном диалоге Revit при перезагрузке).
5. Подтвердите загрузку.

## Обновление/проверка семейств

Одно окно, чтобы увидеть, какие семейства модели отстали от каталога, и обновить их.

1. Нажмите кнопку и выберите категории (можно несколько).
2. В таблице для каждого семейства модели — категория, **статус**, дата в модели, дата похожего файла каталога и насколько похоже имя:
   - **зелёным** «актуально»;
   - **оранжевым** «нет метки» — семейство загружено не через эти кнопки, дату сравнить не с чем;
   - **красным** «устарело» — файл в каталоге новее.
3. Если файл каталога подобран неверно — двойной щелчок по строке или кнопка «Файл…», и укажите нужный файл вручную. Даже файл с другим именем обновит именно это семейство, а не создаст новое.
4. Отметьте галочками семейства для обновления и выберите флажки:
   - **«Заменять значения параметров типоразмеров»** — как «Перезаписать существующую версию и значения параметров» в штатном диалоге;
   - **«Переименовывать»** — дать семейству имя файла из каталога.
5. Подтвердите. Просто закрыть окно — ничего не меняется.

Каждая перезагрузка семейства — отдельный шаг отмены (**Ctrl+Z**).
