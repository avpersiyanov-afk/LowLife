# СОУЭ — расстановка «Типовой этаж»

Кнопка «СОУЭ - расстановка типовой этаж» (панель **SOUE**) расставляет
оповещатели по всем помещениям связанных моделей АР на отмеченных уровнях:

- **в квартирах** — по одному оповещателю на лот, на стену прихожей (или в
  первом найденном помещении из списка в настройках). У двухуровневой
  квартиры — на нижнем уровне. Остальные помещения квартиры не оснащаются;
- **в остальных помещениях** (кроме исключённых) — количество, места, сам
  оповещатель и отвод мощности подбираются по акустическому расчёту: уровень
  звука не ниже шума помещения + 15 дБ на высоте 1,5 м. Настенные ставятся на
  стены и колонны, при подвесном потолке — потолочные.

Все изменения одной транзакцией — откатываются **Ctrl+Z**.

## Что подготовить

- **Связь АР** с помещениями: у квартирных помещений заполнен параметр
  «Имя лота».
- **Семейства оповещателей**, загруженные в проект. Для автоподбора у типа
  (или у стоящего экземпляра) нужны параметры:
  - чувствительность SPL (1 Вт/1 м), дБ — число или текст «87 дБ»;
  - отводы мощности трансформатора, Вт — все через «/»: «1,5 / 3 / 6»;
  - исполнение «Настенный»/«Потолочный» — если параметра нет, исполнение
    ищется в имени семейства/типа («настен», «потол»).

  Все типы проекта, у которых есть параметр SPL, участвуют в подборе —
  кнопка «Оповещатели проекта…» в настройках покажет, что найдено.
- **Параметр «Помещение»** на оповещателях — необязательно, если нужно
  записывать помещение (см. [parameters.md](parameters.md)).

## Настройки (Shift+клик)

Главное окно:

- **Оповещатель квартир** — семейство (с поиском по имени) → тип, установка
  (стена/потолок) и высота.
- **Высота настенных** оповещателей в остальных помещениях.
- **«Помещения объекта: шум и исключения…»** — таблица всех уникальных имён
  помещений из связей: категория по справочнику, уровень шума N (вручную или
  по категории), «исключить». Есть поиск, фильтр «без уровня шума»,
  выгрузка в Excel и загрузка обратно. Новые имена заполняются подсказкой по
  части имени (шахты, ниши, лоджии предлагаются к исключению).
- **«Оповещатели проекта…»** — что найдено для автоподбора.
- **«Параметры и отступы…»**:

| Поле | Что вписать |
|---|---|
| Где ставить оповещатель в квартире | Помещения через запятую по приоритету: «Прихожая, Холл». |
| Параметр помещения «Имя лота» | Параметр помещений связи. Лот, где есть помещение из списка выше, — квартира. |
| SPL / отводы мощности / исполнение | Имена параметров оповещателя (типа или экземпляра). |
| Мощность, если параметра нет, Вт | По умолчанию 1,5. |
| Отступ от углов стены / от дверей и окон, мм | По умолчанию 300 и 200. |
| Допуск по высоте при сопоставлении уровней, мм | Уровень помещения связи совпадает с уровнем модели, если отметки отличаются не больше. |
| Параметр экземпляра «Помещение» | В квартирах пишется имя лота, в остальных — имя помещения. Пусто — не пишется. |

## Как считается

- **Дальность** оповещателя: P0 = SPL + 10·lg P, требуемый уровень
  Nтр = N + 15, rmax = 10^((P0 − 6 − Nтр)/20); в плане
  R = √(rmax² − (h − 1,5)²), где h — высота установки.
- **Места**: помещение покрывается сеткой расчётных точек (шаг 0,5 м);
  кандидаты — вдоль стен и граней колонн вне зон дверей и окон (настенные)
  или узлы сетки (потолочные). Точку озвучивает оповещатель не дальше R, в
  прямой видимости и, у настенного, перед стеной. Подбирается набор с
  наименьшим числом неозвученных точек, затем — штук, затем — суммарной
  мощности.
- **Тип и отвод** перебираются среди всех подходящих оповещателей проекта;
  выбранный отвод пишется в параметр мощности экземпляра, если он
  записываемый.
- **Потолок**: из точки помещения ищется вверх подвесной потолок (в связи);
  если он есть — потолочный тип в его плоскость, иначе — настенный.

## Запуск

1. Нажмите кнопку, отметьте уровни (по умолчанию все).
2. Имена помещений без уровня шума кнопка покажет для ввода; оставшиеся без
   шума пропускаются.
3. Если на уровнях уже стоят оповещатели, кнопка спросит: удалить их и
   расставить заново или оснастить только помещения без оповещателей.
4. В отчёте — таблица по помещениям: уровень, категория, шум, установка,
   высота, дальность, количество, неозвученные точки.
