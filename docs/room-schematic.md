# Рыба структурной схемы (BuildRoomSchematic)

Кнопка панели **Schematic**. Строит черновую «рыбу» структурной схемы **по помещениям**, а не по расставленным устройствам (как кнопки «Структурная схема» СКС/СКУД/СОТ/СПС). Удобна на старте проекта, когда устройств в модели ещё нет, а схему уже нужно показать.

> [!WARNING]
> Кнопка из группы построения схем — тестировалась мало. Результат можно откатить через **Ctrl+Z**.

## Как пользоваться

1. Нажмите кнопку. Откроется одно окно: слева — этажи, справа — помещения выбранного этажа (из модели и из всех связей).
2. В столбце **«На схеме»** напишите, как показать помещение на схеме. Пусто — помещения на схеме не будет.
   - Одинаковая подпись у нескольких помещений этажа — **один общий бокс** («Квартиры», «МОП» и т.п.).
   - Можно выделить несколько строк и задать подпись им всем сразу.
3. Повторите для остальных этажей. Ускорители:
   - этаж с тем же набором помещений, что у уже заполненного (типовой жилой), **заполняется сам**;
   - подписи можно скопировать с любого этажа — сопоставление по именам помещений.
4. Подтвердите — кнопка построит схему.

## Результат

Чертёжный вид «Структурная схема (черновик)»: рамка на каждый этаж и внутри неё по боксу с подписью на каждую подпись. Семейств и линий связи нет — дальше схема дорабатывается вручную.

Подписи запоминаются между запусками, но сам вид **каждый раз перестраивается с нуля** — ручные правки на нём при повторном запуске пропадут. Если схему уже начали дорабатывать, переименуйте или продублируйте вид перед новым запуском.
