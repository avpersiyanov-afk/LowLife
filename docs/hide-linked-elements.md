# Скрыть в связи

Кнопка **Инструменты → Скрыть в связи**, тема **Общее**, Revit 2024+.
Скрывает отдельные элементы связанных моделей на текущем виде по своему условию.
Документы связей и элементы основной модели не изменяются.

1. Откройте обычный графический вид проекта и нажмите кнопку.
2. Задайте проверяемое свойство: имя семейства, имя типа, значение параметра
   или имя рабочего набора. Для параметра задайте имя и источник: экземпляр,
   тип либо экземпляр с переходом к типу только при отсутствии параметра.
3. Выберите условие: содержит, равно, не содержит, не равно, начинается с,
   пусто или не пусто. Введите значение, кроме проверок пустоты.
4. Выберите экземпляры загруженных связей, затем категории элементов.
   Экземпляры одной связи различаются по ID.
5. Проверьте список совпадений. Снимите отметки с элементов, которые нужно
   оставить видимыми, и нажмите **Скрыть выбранные**. Отмена ничего не скрывает.

Условие сохраняется в `%APPDATA%\pyRevit\LowLifeLinkHide_settings.json`.
Обычный клик позволяет проверить/изменить его перед запуском, Shift+клик
открывает только настройки. Доступны общий экспорт/импорт настроек и подсказки
имён параметров из модели и загруженных связей.

Сравнение текстовое, без учёта регистра и пробелов по краям; регулярных
выражений нет. Числа сравниваются по отображаемому тексту в единицах Revit,
а не по числовому диапазону. Отсутствующий параметр не совпадает ни с одним
условием, включая отрицательные. Существующий параметр без значения считается
пустым. При нескольких параметрах с одним именем операция останавливается,
чтобы не скрыть элементы по случайно выбранному параметру.

Это **разовое скрытие на виде**, а не автоматически обновляемый фильтр Revit:
новые элементы и изменившиеся значения требуют повторного запуска. Вернуть
элементы можно штатной командой «Показать скрытые элементы» → «Показать на виде»
либо отменой последней команды. Шаблон вида и переопределения связей кнопка
не меняет. Вложенные связи не обходятся.

Сбор кандидатов использует `FilteredElementCollector(hostDocument, viewId,
linkInstanceId)` (Revit 2024+): это видимость по правилам коллектора Revit,
а не проверка пикселей или перекрытия другими объектами. Для самого скрытия
создаются `Reference(element).CreateLinkReference(link)`, затем вызываются
`Selection.SetReferences` и `PostCommand(HideElements)`. Команда выполняется
Revit после завершения скрипта; успешная постановка в очередь ещё не доказывает
завершение скрытия. Прямой `View.HideElements` с ID из документа связи не используется.

Подход: [пример Autodesk](https://blog.autodesk.io/revit-2025-api-video-and-hiding-linked-elements/).

## Ручная проверка в Revit

- Вставить одну связь дважды. По одному условию скрыть элементы только одного
  экземпляра; второй экземпляр и основная модель должны остаться без изменений.
- Проверить разные категории, параметр экземпляра и типа, пустое значение и
  отсутствующий параметр, отрицательное условие и отсутствие совпадений.
- Снять несколько отметок в списке совпадений; скрыться должны только отмеченные.
- Отменить каждое окно; видимость и исходное выделение не должны измениться.
- Проверить вид с шаблоном, закрытую/выгруженную связь, не поддерживаемый вид,
  недоступную команду скрытия, повторный запуск и Undo после скрытия.
- На русском и английском проверить подписи, подсказки, настройки, поиск
  на ленте и обе темы иконки.

Автоматические проверки: `python -m pytest tests/test_link_hide.py`, затем
`python -m pytest tests`. Они не заменяют проверку внутри Revit.
