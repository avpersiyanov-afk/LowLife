# Notes.panel — «Заметки по проекту»

Панель **Заметки** на вкладке LowLife: заметки, задачи и напоминания по
проекту, которые хранятся в общей Google Таблице команды. Связь с таблицей —
через веб-приложение Google Apps Script (`docs/notes/Code.gs`).

Код: `lib/pnotes/` (`core.py` — настройки, HTTP, сведения о проекте, очередь;
`ui.py` — окна; `xaml/` — разметка окон), кнопки — `LowLife.tab/Notes.panel/`,
напоминания при открытии — в конце `hooks/doc-opened.py`.

## Кнопки

- **Заметка** — Тип → Раздел → Текст, плюс необязательные срок, «кому» и
  привязка выбранных элементов. Код и название проекта, вид, модель и автор
  подставляются автоматически. Ctrl+Enter — сохранить, Esc — отмена.
- **Сводка** — все заметки текущего проекта, в том числе из других моделей с
  тем же кодом проекта. Фильтры по статусу/типу/разделу, поиск, «Только мои»,
  кнопки «Выполнено / В работе / Неактуально / Открыть снова», двойной клик или
  «Показать элементы» — выделить привязанные элементы в модели.
- **Настройка** — адрес и токен подключения + анализ «Сведений о проекте»:
  что заполнено, какой параметр считать кодом проекта, какой — названием,
  какие значения сохранять с каждой заметкой. Выбор параметров общий для всей
  команды (хранится на листе «Настройки» таблицы).

**Напоминания при открытии модели**: просроченные и близкие по сроку заметки +
назначенные вам — не чаще раза за сеанс Revit на проект. Без сети или без
настроенного подключения хук молча ничего не делает и открытию модели не мешает.

**Без интернета** заметка не теряется: она сначала пишется в
`%APPDATA%\pyRevit\ProjectNotes\queue.json` и уходит в таблицу при следующей
заметке или открытии сводки (в сводке такие показаны курсивом со статусом
«Не отправлено»).

## Установка Google-части (один раз на команду)

1. Откройте Google Таблицу — лучше новую. Скрипт создаст листы «Заметки»,
   «Настройки», «Сводка», «Сроки»; если лист «Заметки» уже есть — переименуйте его.
2. **Расширения → Apps Script**, вставьте целиком `docs/notes/Code.gs`, сохраните.
3. Выполните функцию `setup` и выдайте разрешения. Предупреждение «приложение
   не проверено» — нормально: «Дополнительно → Перейти к проекту».
4. Скопируйте токен из журнала выполнения (позже его можно посмотреть в меню
   таблицы «Заметки Revit → Показать токен»).
5. **Развернуть → Новое развертывание → Веб-приложение**, запуск от имени «Я»,
   доступ «Все» → скопируйте URL, который заканчивается на `/exec`.

Про доступ «Все»: сама таблица остаётся закрытой, без токена скрипт ничего не
отдаёт и не принимает. Если Google Workspace организации не даёт выбрать «Все»,
этот способ подключения не подойдёт.

При изменении кода скрипта: **Управление развертываниями → ✏️ → Новая версия**
(если создать новое развертывание, URL сменится и его придётся раздать заново).

## Установка в Revit

Отдельно ничего копировать не нужно — панель приезжает вместе с обновлением
LowLife (менеджер расширений pyRevit → обновить, затем pyRevit → Reload).

Первый запуск: нажмите «Заметка» или «Настройка» → введите адрес (`…/exec`) и
токен → «Проверить связь» → выберите код и название проекта → «Сохранить для
всей команды». Адрес и токен сохраняются только на этом компьютере, в
`%APPDATA%\pyRevit\ProjectNotes\config.json`.

Если параметр кода проекта в модели пуст, используется имя файла (центральной
модели, если модель совместная) — лучше заполнить параметр, иначе заметки
разных моделей одного объекта разойдутся по разным кодам.

> Для администратора: можно положить `config.json` (по образцу
> `config.example.json`) в корень папки расширения — тогда поля заполнятся сами.
> **Не коммитьте его**: репозиторий публичный, `/config.json` стоит в `.gitignore`.
> Личный файл в `%APPDATA%` перекрывает общий.

## Что править потом

- Лист «Настройки»: столбцы «Типы», «Разделы», «Сотрудники» (имена пользователей
  Revit — Параметры → Общие → Имя пользователя), за сколько дней до срока
  напоминать, напоминать ли при открытии модели.
- Статус можно менять прямо в таблице — «Изменено» и «Кто изменил» заполнятся сами.
- Листы «Сводка» (проекты × разделы) и «Сроки» (просроченные и ближайшие 3 дня)
  обновляются формулами.

## Неполадки

- **«Таблица ответила не данными, а страницей»** — не тот URL (нужен `/exec`)
  или у веб-приложения доступ не «Все».
- **«Неверный токен»** — сверьте с меню таблицы «Заметки Revit → Показать токен».
- **«Нет связи с Google Таблицей»** — интернет или прокси до `script.google.com`;
  заметки тем временем копятся локально.
- **Панель «Заметки» не появилась** — pyRevit → Reload после обновления LowLife.

Личные данные на компьютере: `%APPDATA%\pyRevit\ProjectNotes\` — `config.json`
(адрес и токен), `settings_cache.json`, `notes_cache.json`, `queue.json`, `state.json`.
