# LowLife: задания на отверстия

Практическая инструкция для инженеров ВИС, конструкторов КР и архитекторов АР.
Версия интерфейса: компактные вкладки, кнопка «Подсветить на виде».

**Изображения ниже — схемы текущего интерфейса, а не снимки из Revit.**
Подписи вкладок и команд взяты из манифеста плагина. Строки таблиц — учебные;
масштаб и переносы кнопок могут отличаться в зависимости от размера окна и DPI Windows.

## Порядок обмена

1. ВИС расставляет боксы, проверяет их и выдаёт задания КР.
2. ВИС сохраняет/синхронизирует модель; КР обновляет связь ВИС.
3. КР принимает задания или назначает замечания, затем сохраняет свою модель.
4. ВИС обновляет связь КР, выполняет «Обновить обмен» и проверяет результат.
5. После согласования конструктивных отверстий ВИС отдельно выдаёт задания АР.
6. АР принимает свои задания; ВИС обновляет связь АР и подтверждает результат АР.

**Google-журнал фиксирует события, но не обновляет геометрию RVT-связей.**
Сохранение модели и обновление связей обязательны для каждой стороны.

## Что важно знать

- Бокс, черновик и выданное задание — разные состояния. Расстановка ещё не является выдачей.
- Операции применяются к выбранным строкам. Ctrl/Shift позволяют выбрать несколько.
- При изменении трассы повторите расстановку и перевыдайте изменённые боксы.
- Обычный ID элемента используется внутри модели; постоянная связь хранится в GUID задания и UniqueId.
- Полный технический справочник: [Задания на отверстия](../opening-tasks.md).
- Администратору Google: [подключение сервера и выпуск токенов](../opening-journal/README.md).

Функции проверены автоматическими тестами. Иллюстрации не подтверждают запуск
в конкретной версии Revit; первый рабочий цикл проверьте на копиях моделей.


## Обновление иллюстраций для сопровождения

Схемы и PDF собираются командой `python tools/build_opening_tasks_guide.py`
из корня репозитория (CPython, Pillow, reportlab, шрифт DejaVu Sans). Названия
кнопок и групп читаются из `opening_tasks_manifest.py`; содержимое руководств
редактируется в Markdown. После изменения интерфейса схемы и PDF нужно пересобрать.
