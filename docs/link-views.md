# Виды связанных моделей

**LowLife → Общее → Инструменты → Виды связей**. Требуется Revit 2024 или новее.

1. Откройте вид основной модели, для которого нужно настроить связи.
2. Нажмите «Виды связей» и выберите основные виды того же типа, что и текущий.
   Вверху окна галочками выберите настраиваемые модели — выбор действует сразу
   для всех выбранных основных видов. Изначально все галочки сняты — отметьте только нужные модели. Снятие
   галочки скрывает экземпляры модели и исключает их из применения и копирования
   настроек. Уже выбранные назначения сохраняются в окне, если отметить модель снова.
   Для каждого основного вида показан отдельный блок выбранных связей с текущим отображением.
3. Для каждой нужной связи нажмите «Выбрать вид…» и найдите вид по имени.
   После выбора связь автоматически отмечается. Снимите галочку, чтобы оставить её без изменений.
4. При необходимости нажмите «Копировать на другие виды…» в нужном блоке и выберите
   основные виды. Копируются только отмеченные назначения из этого блока, заменяя
   назначения тех же связей в выбранных блоках. Остальные назначения сохраняются.
5. Нажмите «Применить». Для отмеченных экземпляров включается отображение **«По связанному виду»**.

Для одной и той же связи можно назначить разные виды на разных основных видах.
Каждой модели можно назначить свой вид. Несколько экземпляров одной модели
выбираются одной общей галочкой модели, но показаны отдельно с их Id для назначения
видов. Предлагаются только виды того же типа, что и текущий
вид основной модели; шаблоны исключены. Окончательную совместимость проверяет Revit.
Незагруженные связи и связи без подходящих видов показаны, но недоступны для выбора.

Если шаблон текущего вида управляет разделом «Связи Revit», команда объяснит,
что нужно исключить этот раздел из управления шаблоном. Сам шаблон не изменяется.

Изменения записываются одной транзакцией: их можно отменить одним действием
Revit. При ошибке любой связи вся операция откатывается. «Отмена» или закрытие
окна ничего не меняет. Типы связей и документы связанных моделей не редактируются.

Проверка в Revit: назначьте разные виды двум связям и проверьте «Видимость/графика →
Связи Revit», включая два экземпляра одной модели; проверьте отмену операции,
незагруженную связь, шаблон с управляемыми связями и повторное открытие окна.
Также снимите галочку с модели после назначения вида: её экземпляры должны остаться
без изменений на всех основных видах, в том числе после копирования настроек.
