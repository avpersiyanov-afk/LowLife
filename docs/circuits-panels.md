# Электрические цепи — общие кнопки

Кнопки панелей CircuitsSKUD, CircuitsGeneric и CircuitsDelete. Цепи СКС, шлейфов СПС/СПА и цепи изоляторов описаны на страницах своих систем: [СКС](scs-panel.md#цепи-скс-circuitsscspanel--buildcircuitsscs), [СПС/СОУЭ/СПА](fire-alarm-panels.md).

Все кнопки на ленте собраны в теме «Электрические цепи» (выпадающий список «Тема» на панели LowLife). Изменения отменяются через **Ctrl+Z**.

## Цепи СКУД

Строит цепи СКУД вручную: по отдельной цепи от контроллера к каждому устройству («домашний прогон», без промежуточных узлов).

1. Нажмите кнопку.
2. Выберите контроллер и устройства **вместе**, рамкой и/или кликами, в любом порядке; подтвердите Enter или «Готово». Контроллером считается элемент категории «Электрооборудование» — в выборе он должен быть ровно один. Элементы связей выбрать нельзя.
3. Выберите тип цепи — по умолчанию первым в списке стоит Security.

В конце — сколько устройств выбрано, сколько цепей создано и сколько ошибок; подробности ошибок — в окне вывода pyRevit. Частая ошибка — устройство уже входит в другую цепь: такие цепи сначала удалите (кнопка [«Удалить цепи на виде»](#удалить-цепи-на-виде)).

## Цепь (общее)

Строит цепи «панель → устройства» для любой системы — всё, что зависит от дисциплины, задаётся в настройках.

1. Один раз настройте кнопку (**Shift+клик**, см. ниже).
2. Нажмите кнопку и выберите панель и устройства вместе — рамкой и/или кликами, в любом порядке. Панель — элемент категории «Электрооборудование», ровно один. Аннотации, связи, оси, уровни, текст, линии детализации и обобщённые модели в выбор не попадут, даже если захватить их рамкой.

Что кнопка записывает:

- **тип цепи** — из настроек; если там пусто — по коннектору устройства (запасной вариант Data);
- **кабель** — строка справочника кабелей в штатный параметр цепи «Проводник», если она выбрана в настройках (необязательно; про справочник — [docs/cable-catalog.md](cable-catalog.md));
- **«Имя нагрузки»** — собирается из параметров подключаемого устройства по списку через разделитель (например «Розетка.Каб-1»). Для каждого параметра сначала берётся значение экземпляра, если оно пустое — значение типа.

Настройки (**Shift+клик**):

| Поле | Что задаёт |
|---|---|
| Тип электрической цепи | Data, Security, Communication и т.д. — выбор из списка или вручную |
| Признак строки справочника кабелей | необязательно: параметр, по которому кнопка отличает строки справочника от остальных элементов |
| Кабель для цепей | необязательно: строка справочника, которая будет проставлена всем цепям |
| Параметры устройства для имени нагрузки | список имён параметров через запятую, по порядку |
| Разделитель имени нагрузки | текст между значениями, по умолчанию точка |
| Как строить цепи | **отдельная цепь на каждое устройство** (у каждой своё имя нагрузки) или **все устройства в одну цепь** (имя нагрузки не заполняется) |

## Удалить цепи на виде

Удаляет все электрические цепи, у которых хотя бы один элемент — устройство или панель — виден на активном виде.

Нужна, чтобы убрать лишние или тестовые цепи: Revit не даёт добавить в цепь элемент, который уже входит в другую цепь, поэтому кнопки построения цепей (шлейфов, СКС, СКУД) на таких элементах выдают ошибку.

1. Откройте вид, на котором видны нужные элементы.
2. Нажмите кнопку — в окне вывода появится список цепей (по «Номеру цепи», если он задан).
3. Подтвердите удаление.

## Подсветить без цепи

Подсвечивает красным на активном виде все элементы с электрическими коннекторами (устройства, панели, изоляторы и т.п.), у которых ещё нет ни одной цепи — удобно, чтобы не пропустить устройство.

- Подсветка не мешает работать: цепи можно сразу создавать любой кнопкой LowLife или штатной командой Revit. Как только у элемента появляется цепь, подсветка с него снимается сама.
- Повторный запуск на том же виде пересчитывает подсветку (например, если на вид добавили устройства).
- **Shift+клик** — снять подсветку, поставленную кнопкой на активном виде, не дожидаясь появления цепей.
