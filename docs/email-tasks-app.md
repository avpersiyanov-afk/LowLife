# Задачи из почты — программа без Revit

`LowLifeMail.exe` — та же функция, что кнопка «Задачи из почты» в Revit
([docs/email-tasks.md](email-tasks.md)), но отдельной программой: для
тех, у кого Revit нет. Она разбирает «Входящие» классического Outlook за
последние N дней, отдаёт письма ИИ — Claude или ChatGPT — и сохраняет
список задач в Excel.

**Почта только читается**: письма не отправляются, не открываются, не
помечаются прочитанными и не перемещаются.

## Что нужно

- Windows 10 или 11.
- **Классический** Outlook с вашим почтовым профилем. «Новый Outlook»
  (olk.exe) не подходит — у него нет нужного интерфейса для программ;
  переключиться обратно можно переключателем «Новый Outlook» в правом
  верхнем углу окна Outlook.
- Один из способов подключения ИИ — см. ниже.
- Excel — чтобы открыть результат. Сам файл программа пишет без Excel.

Ничего, кроме самой программы, устанавливать не нужно: Python и всё
остальное уже внутри `LowLifeMail.exe`.

## Как скачать

1. Откройте страницу
   [Releases](https://github.com/avpersiyanov-afk/LowLife/releases)
   и найдите последний выпуск «Задачи из почты mail-v…».
2. Скачайте `LowLifeMail.exe` и положите куда удобно (например, на
   рабочий стол или в «Документы»). Установщика нет — это и есть
   программа.
3. При первом запуске Windows может показать «Система Windows защитила
   ваш компьютер»: у программы нет платной цифровой подписи. Нажмите
   «Подробнее» → «Выполнить в любом случае». Если антивирус или
   администратор блокирует запуск — попросите добавить файл в
   исключения.

Новая версия — просто скачайте новый `LowLifeMail.exe` вместо старого;
настройки сохранятся.

## Первый запуск: подключение ИИ

Нажмите **«Настройки»** → «Подключение ИИ» и выберите способ:

| Способ | Что нужно | Как оплачивается |
|---|---|---|
| Claude — приложение Claude Code | Установить Claude Code и войти в аккаунт Claude | Подписка Claude (Pro, Max, Team, Enterprise) |
| Claude — Anthropic API | Ключ API из консоли Anthropic | Отдельно от подписки, по объёму запросов |
| ChatGPT — приложение Codex CLI | Установить Node.js и Codex CLI, войти в аккаунт ChatGPT | Подписка ChatGPT (Plus, Pro, Business, Enterprise) |
| ChatGPT — OpenAI API | Ключ API из консоли OpenAI | Отдельно от подписки, по объёму запросов |

Пошаговые инструкции для каждого способа — в общей инструкции:
[Claude Code](email-tasks.md#claude-code-подписка-claude),
[Anthropic API](email-tasks.md#anthropic-api-ключ),
[Codex CLI](email-tasks.md#codex-cli-подписка-chatgpt),
[OpenAI API](email-tasks.md#openai-api-ключ). Там, где написано
«Revit. Shift+клик по кнопке», в программе нажмите «Настройки»; в окне
настроек у каждого способа тоже есть ссылка на свою инструкцию.
Перезапускать программу после установки Claude Code или Codex не нужно.

**Проверка.** Включите в настройках «Тестовый режим», сохраните и нажмите
«Разобрать почту»: программа возьмёт 6 встроенных выдуманных писем вместо
Outlook и должна найти несколько задач. Получилось — выключите тестовый
режим.

## Работа

1. Запустите классический Outlook (если не запущен — программа запустит
   его сама в фоне).
2. Нажмите **«Разобрать почту»**. Внизу видно, что происходит: чтение
   писем, затем разбор пачками («часть 1 из 3»). «Отмена» останавливает
   разбор.
3. Найденные задачи появятся в таблице (щелчок по строке — подробности
   внизу), а Excel-файл сохранится в
   `Документы\Задачи из почты\Задачи_<дата>.xlsx` и откроется сам.
   Кнопки «Открыть Excel» и «Открыть папку» — чтобы вернуться к нему.

В Excel у каждой задачи есть столбец «Статус» с выпадающим списком (не
начато / в работе / ждёт ответа / готово); просроченные задачи
подсвечиваются красным, высокий приоритет — жёлтым, готовые — серым.

Остальные настройки — период (сколько дней разбирать), только
непрочитанные, подпапка «Входящих», включая подпапки, промпт — те же, что
у кнопки в Revit; подробно — в [общей инструкции](email-tasks.md#настройки-shiftклик).

## Где хранятся настройки

`%APPDATA%\LowLife\LowLifeEmailTasks_settings.json`. Если на компьютере
уже настроена кнопка в Revit (есть
`%APPDATA%\pyRevit\LowLifeEmailTasks_settings.json`), программа берёт её
файл — настройки у них общие.

Ключ API, если вы его вписали, хранится в этом файле открытым текстом. Не
пересылайте файл. Вместо этого можно задать переменную окружения
`ANTHROPIC_API_KEY` или `OPENAI_API_KEY` и оставить поле ключа пустым
(после `setx` перезапустите программу).

## Если что-то не так

- **«Классический Outlook не найден» / «Не удалось подключиться к
  Outlook»** — запустите классический Outlook (не «новый») и повторите.
  Outlook и программа должны быть запущены от одного пользователя:
  если одна из них «от имени администратора», а другая нет, подключения
  не будет.
- **Claude Code / Codex «не залогинен» или «не найден»** — см. раздел
  [Сообщения об ошибках](email-tasks.md#сообщения-об-ошибках) общей
  инструкции.
- **Ответ ИИ не разобрался** — он сохранён в
  `%TEMP%\LowLifeEmailTasks\answer_*.txt`, остальные пачки разбираются
  дальше.
- Вопрос или ошибка — напишите автору LowLife.
