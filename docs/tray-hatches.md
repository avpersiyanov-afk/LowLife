# Лючки на уровнях (TrayHatches)

Кнопка панели **ToolsTraySection** («Лотки»). Ставит лючки там, где кабельные лотки проходят через уровни, — семейство, в имени типа которого есть «лючок», с размерами лотка плюс запас (по умолчанию 50 мм).

## Что нужно в модели

- Загруженное семейство лючка, в **имени типа** которого есть «лючок» (текст меняется в настройках). Семейство — на основе уровня или рабочей плоскости, не на грани и не на основе перекрытия/стены. Точка вставки семейства — в центре лючка: кнопка поворачивает его вокруг этой точки.
- Два параметра длины в семействе — ширина и длина лючка. Ширина идёт по оси X семейства.

## Как пользоваться

1. Shift+клик — заполните настройки (один раз):
   - **часть имени типа** — по умолчанию «лючок»;
   - **параметр ширины** — в него пишется ширина лотка + запас;
   - **параметр длины** — высота лотка + запас;
   - **запас к размерам лотка, мм** — по умолчанию 50 (всего, не с каждой стороны);
   - **смещение от уровня, мм** — 0, если лючок на отметке уровня.
2. Выделите лотки или ничего не выделяйте (тогда берутся все лотки модели).
3. Нажмите кнопку. Если подходящих типов лючка несколько — выберите нужный.

## Как считается

- Через уровень «проходит» лоток круче 30° к горизонту, ось которого пересекает отметку уровня (плюс смещение). Если участок кончается ровно на уровне, точка считается только когда к этому концу что-то присоединено (трасса продолжается); одна и та же точка с соседних участков не дублируется.
- Ширина лючка — вдоль ширины лотка, длина — вдоль его высоты. У наклонного лотка длина берётся по косому сечению лотка уровнем (оно длиннее высоты лотка).
- Параметры экземпляра пишутся в сам лючок. Если параметры размеров — параметры типа, кнопка берёт тип того же семейства с нужным размером или создаёт его копией выбранного типа («<тип> 300×200»).
- Лючок попадает в рабочий набор своего лотка.
- Повторный запуск не ставит копии: лючок того же семейства на том же уровне в радиусе 100 мм от точки обновляется — размер и поворот подстраиваются под лоток. Лючки там, где лотка больше нет, не удаляются.
- Учитываются только лотки текущей модели, не связей.
