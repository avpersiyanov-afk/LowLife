# Tray*.panel — создание кабельных лотков

Пять панелей на ленте LowLife, каждая — один конструктив лотка, с четырьмя
одинаковыми кнопками («Лоток СПЗо» / «Лоток СПЗп» / «Лоток СБ» / «Лоток СС» —
по системе, для которой прокладывается лоток). Всего 20 кнопок, вся логика —
в `lib/lowlife/cable_tray.py` (`run_tray_button`), настройки — в
`lib/lowlife/cable_tray_settings.py`.

## Что нужно создать в проекте

1. **Типы кабельных лотков.** Кнопка не создаёт тип, а ищет готовый. Создайте
   в проекте (или загрузите из шаблона) типы кабельных лотков, в имени
   которых есть текст из таблицы ниже, — по одному типу на кнопку. Имя
   может быть длиннее (например `КЛ_СБ_ЛЛ_1.5_СЦ_200х100`), но текст должен
   встречаться ровно в одном типе.
2. **Рабочий набор**, в имени которого есть «КНК» (ровно один такой). В него
   кнопки кладут новые лотки. Проект должен быть с совместной работой.

Если в вашем проекте типы или рабочий набор называются иначе — не
переименовывайте их, а поменяйте текст в настройках кнопки (см. ниже).

Имена типов по умолчанию:

| Панель | Лоток СПЗо | Лоток СПЗп | Лоток СБ | Лоток СС |
|---|---|---|---|---|
| Лестничный лоток | `СПЗо_ЛЛ_1.5_СЦ` | `СПЗп_ЛЛ_1.5_СЦ` | `СБ_ЛЛ_1.5_СЦ` | `СС_ЛЛ_1.5_СЦ` |
| Неперфорированный лоток | `СПЗо_ЛН_1.5_СЦ` | `СПЗп_ЛН_1.5_СЦ` | `СБ_ЛН_1.5_СЦ` | `СС_ЛН_1.5_СЦ` |
| Перфорированный лоток | `СПЗо_ЛП_1.5_СЦ` | `СПЗп_ЛП_1.5_СЦ` | `СБ_ЛП_1.5_СЦ` | `СС_ЛП_1.5_СЦ` |
| Проволочный лоток | `СПЗо_ЛВ_1.5_СЦ` | `СПЗп_ЛВ_1.5_СЦ` | `СБ_ЛВ_1.5_СЦ` | `СС_ЛВ_1.5_СЦ` |
| Лотки на кровле | `СПЗо_ЛП_1.5_ГЦ` | `СПЗп_ЛП_1.5_ГЦ` | `СБ_ЛП_1.5_ГЦ` | `СС_ЛП_1.5_ГЦ` |

Панели на ленте лежат в папках `TrayLadder.panel`, `TrayUnperforated.panel`,
`TrayPerforated.panel`, `TrayWire.panel`, `TrayRoof.panel`.

## Настройки (Shift+клик)

Shift+клик по любой кнопке лотка открывает окно с двумя полями:

- **① Тип лотка этой кнопки** — часть имени типа кабельного лотка. Своё у
  каждой кнопки, по умолчанию — значение из таблицы выше.
- **② Рабочий набор** — часть имени рабочего набора, по умолчанию «КНК».
  Общее для всех 20 кнопок: поменяли у одной — поменялось у всех.

Кнопка «Сбросить» возвращает умолчания. Настройки хранятся в
`%APPDATA%\pyRevit\LowLifeCableTray_settings.json` (один файл на все кнопки),
их можно выгрузить и загрузить на другом компьютере.

## Что делает кнопка

1. Ищет среди `CableTrayType` проекта ровно один тип, в имени которого есть
   текст из настройки ①. Если таких типов 0 или больше 1 — сообщение с
   остановкой, без угадывания.
2. Ищет среди пользовательских рабочих наборов ровно один, в имени которого
   есть текст из настройки ②, и делает его активным
   (`WorksetTable.SetActiveWorksetId`) — так новый лоток создаётся в
   правильном рабочем наборе.
3. Запускает штатный интерактивный инструмент Revit «Лоток» уже с найденным
   типом через `UIDocument.PostRequestForElementTypePlacement` — дальше
   пользователь рисует лоток мышью в модели как обычно.

Если версия Revit не поддерживает `PostRequestForElementTypePlacement` —
кнопка всё равно переключает рабочий набор и сообщает, какой тип выбрать
вручную в инструменте «Лоток».

## Темы (`_Themes.panel`)

Все пять панелей и все 20 кнопок зарегистрированы в `panel_themes.THEMES`
под своей темой — `u"КНК"` (название — по рабочему набору, в который они
переключают проект, а не по дисциплине: создание лотков не привязано к
одной конкретной системе). В переключателе тем (`ThemeSelector.combobox`)
это пункт «КНК». Выбор темы «КНК» показывает только Tray*.panel;
любая другая тема их скрывает — как и остальные дисциплины.

Так как у каждой Tray*.panel есть свой `title:` в bundle.yaml (например,
«Лестничный лоток» у `TrayLadder.panel`), а `RibbonPanel.Name` в рантайме —
это отображаемый заголовок, а не имя папки, все пять панелей добавлены в
`PANEL_RIBBON_NAMES` (иначе `_find_panel` искал бы панель по имени папки
`"TrayLadder"` и не находил бы её на ленте — тот самый повторяющийся баг
«панель игнорирует переключатель тем» из-за несовпадения title≠имя папки).
