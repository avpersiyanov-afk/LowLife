# Подготовка переноса после тестирования

Настройки и журнал отверстий не импортируют пакет pnotes и не читают
настройки, кеш, URL или токены «Заметок». Администратор остаётся persiyanov.

Для параметра шифра используется собственное поле opening_project_param
в настройках заданий. Пустое значение означает стандартный «Номер проекта».
Если раньше шифр наследовался из «Заметок», имя нужного параметра теперь
нужно один раз указать в настройках заданий.

Общие функции не дублируются:
- cloud_io.py — извлечённые HTTP, ASCII-JSON и блокировка AppDomain;
- background.py — извлечённый обработчик фоновых запросов окон;
- params.read_project_parameter — чтение пользовательских и встроенных ссылок.

«Заметки» используют совместимые адаптеры этих функций, а задания — собственный
экземпляр транспорта. Закрытие окна одного инструмента не отменяет запросы другого.

При переносе после тестирования:
1. Перенести нужные модули opening_tasks_*, opening_levels_* и их общие зависимости
   из lib/lowlife; сам пакет pnotes для заданий не нужен.
2. Перенести интерфейсы ВИС/КР/АР, их ресурсы и регистрацию панели/тем/переводов.
3. Перенести блок запуска тихой очереди в startup/hooks целевого расширения.
4. Установить Code.gs в целевой Google-журнал и выдать нужные токены групп.
5. Настроить собственный параметр шифра и выполнить установку подключения
   в профиле пользователя. Не коммитить токены и локальные файлы подключений.
6. Проверить полный цикл на тестовых моделях перед рабочим использованием.

Зашифрованные DPAPI-подключения нельзя переносить между профилями Windows.
Названия файлов LowLifeOpeningTasks* и LowLifeOpeningJournal* сохраняют
совместимость текущей установки. Изменять их для нового продукта следует
с явной миграцией, чтобы пользователи не потеряли настройки и очередь.

Эта инструкция готовит перенос. Новый репозиторий и его развёртывание пока
не создавались: они выполняются после проверки текущей версии.
