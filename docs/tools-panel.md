# Панель Tools — общие инструменты

Кнопки, не привязанные к дисциплине. Здесь описаны те, у которых нет отдельной инструкции; про «Виды по уровням», «Марки оборудования», «Проверку орфографии» и «Параметры в ФОП» — отдельные страницы (ссылки в [README](../README.md#панели-и-кнопки)).

Все изменения в модели, которые вносят кнопки, отменяются через **Ctrl+Z**.

## ID элемента

Показывает ID выбранного элемента и сразу копирует его в буфер обмена.

1. Выберите элемент (можно выбрать элемент внутри связанной модели — Tab до нужного элемента связи).
2. Нажмите кнопку.

Для элемента связи показывается его ID **в связанном файле**, а не ID экземпляра связи. Если выбрано несколько элементов, в буфер попадает список ID через запятую — его можно вставить в штатный диалог Revit «Выбрать элементы по ID» (Select Elements by ID).

## Размеры осей

Образмеривает выбранные оси одной цепочкой и общим размером.

1. Выделите на виде минимум две оси (одного направления).
2. Нажмите кнопку и выберите тип размера из списка.

Кнопка строит размерную цепочку между соседними осями на отступе 1400 мм от концов осей и, если осей три и больше, общий размер от первой оси до последней — ещё на 700 мм дальше.

## Длина линий

Суммирует длины выбранных обобщённых моделей по типам — например, чтобы быстро посчитать длину трасс, нарисованных линейными семействами.

1. Выделите элементы (лишние категории можно не убирать — учитываются только обобщённые модели).
2. Нажмите кнопку.

В окне вывода — длина по каждому типу в метрах и общая длина. Длина берётся по линии элемента, а если её нет — из параметра «Длина»/«Length»/«L» экземпляра или типа.

## Разрез по семейству

Строит разрез по выбранному элементу, уже обрезанный, с шаблоном вида, типоразмером и именем по маске.

1. Выделите один или несколько элементов (или нажмите кнопку без выделения — она попросит выбрать их в модели). Подходят семейства и линейные элементы: кабельные лотки, короба, трубы, воздуховоды, стены.
2. Если элементов несколько — выберите: один общий разрез (границы по крайним элементам) или по разрезу на каждый.
3. Укажите, насколько опустить низ разреза ниже базового уровня (мм). Ответы запоминаются до следующего раза.

Как строится разрез:

- **по высоте** — от базового уровня элемента до следующего этажа того же корпуса (следующий этаж ищется по имени уровня и шаблону из настроек; уровни других корпусов на разрезе скрываются);
- **по ширине** — 2000 мм слева и справа от элемента;
- **по глубине** — секущая плоскость в 100 мм перед элементом, дальняя граница в 1000 мм за ним;
- **направление** — на лицевую сторону семейства; для устройства на стене — со стороны помещения; у линейных элементов — вдоль оси, взгляд с юга (для осей «север–юг» — с запада).

**Shift+клик** — настройки: шаблон вида, типоразмер разреза, маска имени, отступы подрезки, шаблон имени уровня (по умолчанию `{Дисциплина}_{Корпус}_{Отметка}_{Этаж}_{Комментарий}`), «смотреть с обратной стороны».

## Секущий диапазон

Выравнивает секущий диапазон планов по единому правилу:

| Граница | Значение |
|---|---|
| Низ и глубина | уровень плана |
| Секущая плоскость | уровень плана +1200 мм (если до следующего этажа меньше 1400 мм — +900 мм) |
| Верх | уровень следующего этажа −200 мм (если выше уровней нет — «Неограниченно») |

1. Выделите планы в Диспетчере проекта — или просто откройте нужный план.
2. Нажмите кнопку.

Следующий этаж ищется по имени уровня: тот же корпус, другой этаж. Шаблон имени уровня задаётся в настройках (**Shift+клик**), например `{Дисциплина}_{Корпус}_{Отметка}_{Этаж}_{Комментарий}` или `Этаж {Этаж}`. Планы потолков и планы, у которых секущий диапазон задаёт шаблон вида, пропускаются — кнопка скажет почему.

## Обход линий

Рисует дугу-«перескок» одной линии детализации через другую на пересечении (как обход на схемах).

1. Нажмите кнопку и введите диаметр дуги.
2. Выберите режим:
   - **Одиночный** — своя дуга ровно заданного диаметра на каждом пересечении;
   - **Множественный** — одна большая дуга на весь пучок, если линия сразу пересекает несколько базовых.
3. Выберите базовые линии — рамкой и/или кликами, подтвердите Enter или «Готово». Базовые линии остаются целыми.
4. Дальше по кругу: щёлкните линию, которая должна обойти базовые, затем — сторону обхода. Дуга строится сразу.

**Esc** на выборе линии — закончить работу, **Esc** на выборе стороны — пропустить только эту линию.

## Лотки связи в Эксель

Выгружает в .xlsx список кабельных лотков из связанной модели, которые видны на активном виде. Excel для этого не нужен.

1. Откройте вид, на котором видна связь с лотками.
2. Нажмите кнопку. Если связей на виде несколько — отметьте, из каких собирать.
3. Укажите, куда сохранить файл.

Столбцы: ID лотка в связанном файле, имя типа, модель, отметка середины (мм), базовый уровень, имя связи. В Revit 2024 и новее видимость определяется точно по виду, в более старых — по подрезке и секущему диапазону.

## DWG → чертёжный

Обводит DWG-подложку аннотациями Revit: линии, дуги и полилинии становятся линиями детализации, текст — текстовыми примечаниями в той же точке, с тем же поворотом, выравниванием и высотой на бумаге.

1. Выделите DWG на виде (или не выделяйте — возьмётся видимый на виде; если их несколько — выбор из списка).
2. Выберите, куда переносить: в **новый чертёжный вид** (он откроется) или **на этот же вид** поверх подложки.

Слои, скрытые на виде, не переносятся.

Текст DWG Revit не видит, поэтому кнопка читает его из DXF того же чертежа:

1. DXF с тем же именем рядом с DWG;
2. иначе — конвертирует DWG бесплатным [ODA File Converter](https://www.opendesign.com/guestfiles/oda_file_converter), если он установлен;
3. иначе — предложит указать DXF вручную или перенести только линии.

**Shift+клик** — настройки: один стиль линий для всего или стили по слоям DWG (с цветом слоя), исходный типоразмер текста, путь к ODA File Converter.

## Приветствие

Окно с приветствием большими буквами: «Доброе утро / день / вечер» по времени суток и имя пользователя Revit. Иногда — шутка: ночью (23:00–5:00) и в выходные — что так работать не стоит, днём в будни (12:00–17:00) — про опоздание, вечером в будни (17:00–23:00) — что пора домой, утром в будни — пожелание на день.

Закрыть — щелчок по окну, Enter или Esc. Показывать ли приветствие при каждом запуске Revit, выбирается галочкой в окне «О программе» (по умолчанию выключено); эта кнопка показывает его в любой момент.

## Зум к элементу

Приближает вид к элементу.

- Если элементы выбраны — приближает к ним (к нескольким — к их общему габариту).
- Если ничего не выбрано — спрашивает ID элемента.

Если элемент на активном виде не виден, кнопка подскажет, на какой вид (план, разрез, 3D) переключиться.

## Обрезать вид

Обрезает вид и аннотации по прямоугольнику, указанному мышью.

1. Откройте план, разрез, фасад или узел.
2. Щёлкните два противоположных угла рамки.
3. Выберите, что обрезать: **этот вид** или его **копию** — простую, с детализацией или зависимую. Для копии укажите текст, который добавится в конец имени.

Включаются подрезка вида и подрезка аннотаций (с минимальным отступом от рамки); копия сразу открывается. **Esc** — отмена.

Обрезанный так план можно использовать для кнопки [«Экспликация фрагмента»](rooms-panel.md#экспликация-фрагмента).

## Повернуть 3D вид

Разворачивает открытый 3D вид так, чтобы смотреть вдоль или поперёк выбранной оси.

1. Откройте 3D вид (заблокированный вид сначала разблокируйте).
2. Укажите ось одним из способов:
   - выберите ось сетки из списка — там оси модели и загруженных связей (в 3D Revit их не показывает);
   - щёлкните на виде прямую линию, стену или лоток — в модели или в связи.

Вид поворачивается вокруг вертикали на ближайший из четырёх углов «вдоль/поперёк», наклон камеры не меняется. Если включена рамка 3D вида, она поворачивается так же — её стороны встают параллельно оси. **Esc** — отмена.
