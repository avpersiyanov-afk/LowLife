# Маркировка задания для АР

Кнопка на панели «Инструменты», тема «Общее». Создаёт текстовые примечания
с выноской к каждому видимому экземпляру выбранного типоразмера в текущей
модели на активном плане. Текст берётся из настроек кнопки.

1. Нажмите **Shift+клик** по кнопке.
2. Отметьте нужные типы семейств в списке с поиском. В нём есть и загруженные
   типы, которые ещё не размещены в модели. Нажмите «Далее — текст и отступы».
3. Выберите тип текста Revit и задайте текст для каждого типоразмера.
   Пустой текст отключает создание и обновление подписи этого типа.
   Для переноса строки введите `\n`.
4. Сохраните настройки. Откройте нужный план и нажмите кнопку обычным кликом.

При первом запуске без настроек окно откроется автоматически. Настройки
сохраняются в `%APPDATA%\pyRevit\LowLifeARTaskAnnotations_settings.json`.
Типоразмеры сопоставляются по категории, имени семейства и имени типа,
поэтому разные типы одного семейства могут иметь разные тексты.
В окне доступны обычные выгрузка и загрузка настроек LowLife.

Раскладка использует тот же механизм, что «Марки оборудования»: стопки и
колонки, обход соседнего оборудования, марок и текста, выноска к краю УГО.
Отступ, зазор, полка и расстояние объединения в группу задаются в мм на листе
и пересчитываются по масштабу плана. Если места недостаточно, отчёт показывает
оставшиеся наложения и пересечения выносок.

Повторный запуск обновляет текст, стиль и расположение созданных кнопкой
примечаний. Привязка к экземпляру хранится внутри примечания. Закреплённые
примечания пропускаются. Пользовательские тексты и марки остаются препятствиями.
Существующие подписи отключённых типов сохраняются; для удаления используйте Revit.
Если подпись скопирована вручную и один экземпляр получил несколько подписей
этой кнопки на одном виде, команда попросит удалить лишние копии.

Это обычный текст Revit: после перемещения семейства заново запустите кнопку,
чтобы обновить конец выноски. Элементы связей не обрабатываются. Изменения
выполняются одной транзакцией и отменяются одним Ctrl+Z. При ошибке текст и
его привязка откатываются вместе.

Проверено автоматическими тестами вне Revit. Нативные создание текста,
отрисовка выносок и окно настроек в Revit в этой сессии не проверялись.
