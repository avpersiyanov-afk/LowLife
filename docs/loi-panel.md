# Панель LOI — заполнение и проверка параметров

Четыре кнопки панели **LOI** («Заполнение LOI»): заполнить параметры элементов
по контексту и проверить, что всё заполнено. Изменения модели откатываются
**Ctrl+Z**.

## Заполнение LOI

Копирует значения параметров из элементов категории **«Формы»** во все
проверяемые элементы, которые физически находятся внутри солида формы
(корпус, секция, этаж… — то, что заведено на «Формах»). Проверка точная, по
солиду: у точечных элементов — попадание точки, у линейных (лотки, трубы) —
пересечение линии с солидом.

- Элемент ровно в одной форме заполняется сразу.
- Элемент сразу в нескольких формах (обычно линейный на границе) по умолчанию
  **разрезается** по границе форм, каждый кусок получает значения своей формы.
  Что разрезать не удалось — попадает в таблицу конфликтов, где для каждого
  выбирается форма-источник.

Настройки (Shift+клик):

1. **В каких моделях искать «Формы»** — текущий файл и/или конкретные
   загруженные связи (формы обычно лежат в отдельной архитектурной модели).
2. **Параметры для клонирования** — по одному на строке. Имя должно совпадать
   у «Формы» и у целевого элемента.
3. **Какие элементы проверять** — все на активном виде, все в документе или
   только выбранные типы семейств.
4. **Элемент сразу в нескольких формах** — разрезать по границе или сразу
   отдавать в таблицу конфликтов.

Те же настройки использует кнопка [«СС1-8Mile»](ss1.md) для заполнения LOI
у расставленного оборудования.

## Заполнение этажа

Пишет в один параметр (например «Этаж») значение по **уровню элемента** — так,
как он указан в свойствах экземпляра («Уровень»), а не по положению на плане.
Проходит по всем элементам документа, без привязки к активному виду.

Настройки (Shift+клик):

- **Параметр «Этаж»** — куда писать. Создать его и привязать к нужным
  категориям можно кнопкой «Параметры в ФОП» (система «Заполнение этажа»;
  категории выбираются вручную, см. [parameters.md](parameters.md)).
- **Таблица «Уровень / Значение»** — все уровни документа; для каждого
  впишите, что записать его элементам («1», «Этаж 1», «-1»…). Пустое
  значение — элементы этого уровня пропускаются.

Элементы без уровня пропускаются. В отчёте — сколько записано и где запись не
удалась (параметра нет у элемента или он только для чтения).

## Проверка LOI

Проверяет, заполнены ли у элементов выбранных категорий нужные параметры
(значение ищется у экземпляра, потом у типа), и строит:

- по каждой категории спецификацию **«LOI проверка — <категория>»**: столбцы
  «Тип», «Семейство», «Этаж» и проверяемые параметры, сортировка
  этаж → семейство → тип. Повторный запуск пересобирает ту же спецификацию;
- **3D-вид «LOI проверка — незаполненные»**, где видны только элементы с
  незаполненными параметрами (после проверки кнопка спросит, открыть ли его);
- **отчёт**: сколько элементов не заполнено по каждому параметру и их список
  (ID кликабельный).

Два режима:

- **Свой список** — в настройках выбираются категории, затем параметры
  построчно (как в требованиях LOI), затем для каждой строки — имя параметра в
  модели (пусто — сама строка).
- **По приложению «Требования к LOI»** — загрузите в настройках приложение
  (таблица Excel, сохранённая как «Таблица XML 2003»), выберите разделы. При
  запуске кнопка спросит этап: стадия · ПЧ/НЧ · подэтап (Б-1…, ПЭ-1…).
  Категории и параметры берутся из приложения; у каждого элемента проверяются
  только параметры его класса (по коду классификатора в параметре, указанном
  в заголовке столбца кода), обязательные к этому подэтапу.

**Параметр для столбца «Этаж»** — в настройках; пусто — параметр кнопки
«Заполнение этажа», а если и он не задан — уровень элемента.

Параметр попадёт в спецификацию, только если это общий параметр или параметр
проекта, привязанный к категории; иначе он показывается в отчёте с причиной.

## Обновить имя уровня

Назначает опорный уровень выбранным экземплярам семейств, у которых его нет и
нет основы (например, вставленным без уровня). Уровень — выбранный из списка
или по высоте: ближайший уровень не выше элемента.

Сначала кнопка пробует просто прописать параметр «Уровень» — элемент остаётся
на месте. Если Revit не даёт его менять, после подтверждения экземпляр
пересоздаётся с уровнем на том же месте: тип, поворот/отражение, параметры
экземпляра, рабочий набор и электрические цепи переносятся, но **ID элемента
меняется, а марки старого удаляются**.

Элементы с уровнем, на основе, вложенные и в группах пропускаются. После
работы выделены получившиеся элементы.
