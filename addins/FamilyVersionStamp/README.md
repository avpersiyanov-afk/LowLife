# FamilyVersionStamp

Отдельный Revit-аддин (не часть pyRevit-расширения `LowLife.tab`) —
команда во вкладке **Надстройки → Внешние инструменты**. Работает
только с открытым в Редакторе семейств документом (`.rfa`).

## Что делает

1. Проверяет, что активный документ — семейство, и что в нём есть
   текстовые параметры семейства **«Дата»** и **«Версия»** (их нужно
   завести заранее в диспетчере параметров семейства — команда их не
   создаёт, только сообщает, если чего-то не хватает).
2. Пишет во все типоразмеры семейства:
   - «Дата» — текущая дата (`dd.MM.yyyy`);
   - «Версия» — `ver.1`, если было пусто/не в формате `ver.N`;
     `ver.(N+1)`, если было `ver.N`.
3. Сохраняет файл семейства (`Document.Save()`). Если семейство ещё ни
   разу не сохранялось на диск — выводит предупреждение и просит
   сохранить вручную (Save As), путь придумывать не пытается.

## Сборка

Нужен .NET SDK 8 (устанавливался в `%USERPROFILE%\.dotnet` — если его
нет в `PATH`, добавить временно: `$env:PATH = "$env:USERPROFILE\.dotnet;$env:PATH"`).

```powershell
cd addins/FamilyVersionStamp
dotnet build -c Release
```

Проект ссылается на `RevitAPI.dll`/`RevitAPIUI.dll` из установленного
Revit — по умолчанию `C:\Program Files\Autodesk\Revit 2024`. Для другой
версии Revit собрать так:

```powershell
dotnet build -c Release -p:RevitInstallDir="C:\Program Files\Autodesk\Revit 2025"
```

Результат: `bin\Release\FamilyVersionStamp.dll`.

## Установка в Revit

`FamilyVersionStamp.addin` (манифест) уже скопирован в
`%APPDATA%\Autodesk\Revit\Addins\2024\FamilyVersionStamp.addin` на
этой машине — путь к DLL внутри указан абсолютный, на
`bin\Release\FamilyVersionStamp.dll` в этой же папке репозитория.

При переносе на другую машину или под другую версию Revit:

1. Собрать DLL под нужную версию (см. выше).
2. Скопировать `FamilyVersionStamp.addin` в
   `%APPDATA%\Autodesk\Revit\Addins\<версия>\` (или
   `%ProgramData%\Autodesk\Revit\Addins\<версия>\` для всех
   пользователей).
3. В скопированном манифесте поправить путь в `<Assembly>` на реальный
   путь к собранной DLL на этой машине.

Чтобы отключить — удалить `.addin`-файл из папки Addins (сама DLL и
исходники в репозитории не мешают).

## Ограничения / допущения

- Параметры «Дата»/«Версия» должны быть текстовыми (Text) параметрами
  семейства — не общими/встроенными, а именно параметрами семейства
  (Family Parameter), созданными в диспетчере параметров.
- Если один из параметров задан формулой (`IsDeterminedByFormula`) —
  команда его не трогает (Revit всё равно не даст записать в него
  значение напрямую).
- Формат версии жёстко `ver.N` (регистронезависимо к `ver.`); любое
  другое содержимое считается «пустым» и заменяется на `ver.1`.
