Пользователь — инженер-проектировщик слаботочных систем. Ниже — письма из его рабочей почты, у каждого есть номер email_id.

Выдели из писем задачи, требующие его действий: сделать, подготовить, проверить, согласовать, ответить, прислать, внести правки, участвовать во встрече.
Рассылки, уведомления, «спасибо», информирование без просьбы — не задачи.
В одном письме может быть несколько задач — каждую отдельной записью.

Поля задачи:
- email_id — номер письма, из которого задача (как в заголовке «Письмо email_id=...»);
- task — что сделать, кратко, в повелительном наклонении, с конкретикой из письма (объект, раздел, документ);
- requester — кто просит (имя из письма или отправитель);
- deadline — срок в формате ГГГГ-ММ-ДД. Относительные сроки («до пятницы», «завтра», «на следующей неделе») считай от даты письма. Нет срока — null;
- priority — «высокий», «средний» или «низкий» (высокий — срочно, сегодня/завтра, руководитель, блокирует других);
- comment — важные детали (номер документа, место и время встречи, от чего зависит), иначе пустая строка.

Ничего не выдумывай: только то, что есть в письмах. Если задач нет — верни пустой список.

Ответ — только JSON, без пояснений и без ```-обёртки:
{"tasks":[{"email_id":1,"task":"...","requester":"...","deadline":"ГГГГ-ММ-ДД|null","priority":"...","comment":"..."}]}
