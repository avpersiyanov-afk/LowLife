# LowLife

pyRevit-расширение для проектирования слаботочных систем (СКС, СКУД, СПС, СОУЭ, СПА) в Autodesk Revit: скрипты IronPython/CPython 2, запускаются внутри Revit через pyRevit.

> [!WARNING]
> **Это тестовый продукт.** Кнопки, связанные с построением структурных схем (СС) — «Структурная схема» СКС/СКУД/СОТ/СПС, «Рыба структурной схемы» и другие, — тестировались мало, результат может быть непредсказуемым. Все изменения, которые вносят кнопки, можно откатить через **Ctrl+Z** в Revit.

Новости, обновления и обсуждение — в Telegram-канале [t.me/rvt_lowlife](https://t.me/rvt_lowlife).

## Установка

Добавьте расширение в pyRevit по ссылке на этот репозиторий (Extensions → Add from GitHub URL). pyRevit сам клонирует репозиторий в `%APPDATA%\pyRevit\Extensions\LowLife.extension\` — вкладка `LowLife.tab` должна оставаться в корне репозитория, отдельной папки-обёртки `.extension` в самом репозитории нет и быть не должно.

Обновление — повторный pull через менеджер расширений pyRevit и перезагрузка pyRevit / перезапуск Revit.

## Поддерживаемые версии Revit

| Версия Revit | Статус |
|---|---|
| 2024 | основная рабочая версия — на ней проверяется поведение API |
| 2025, 2026 | поддерживается: учтён переход Revit на .NET 8 (открытие ссылок, Outlook, завершение процессов) |
| 2022–2023 | должно работать: там, где API менялся, есть откаты на старые вызовы (`ElementId.IntegerValue`, `ParameterType`), но отдельно не проверялось |
| 2021 и старше | не поддерживается |

Жёсткого ограничения по версии в кнопках нет (`min_revit_version`/`max_revit_version` не заданы): расширение загрузится в любой Revit, который поддерживает установленный pyRevit. Скрипты написаны на IronPython 2 и рассчитаны на стандартный движок pyRevit, поэтому нужна версия pyRevit, поддерживающая вашу версию Revit (для Revit 2025+ — pyRevit 5.x).

Эти же сведения и ваша текущая версия Revit показаны в окне «О программе» (первая кнопка ленты). Если меняете таблицу, поправьте и `REVIT_SUPPORT` в `lib/lowlife/about.py`.

## Параметры

Какие параметры должны быть у каких категорий элементов (узлов трассы, устройств, панелей, электрических цепей, схемных семейств, видов) — в общем списке [docs/parameters.md](docs/parameters.md). Ссылка на неё есть и в окне «О программе».

Быстрее всего подготовить проект кнопкой **«Параметры в ФОП»** (панель Tools): она показывает нужные параметры выбранных систем, подставляет похожие из вашего ФОП, привязывает их к категориям и вписывает имена в настройки кнопок. Одна и та же роль называется одинаково во всех кнопках — имя, введённое в одной кнопке, подставится в остальные. Штатные параметры Revit («Панель», «Имя нагрузки», «Проводник» цепи, рабочий набор) в настройках не спрашиваются — кнопки работают с ними сами.

## Панели и кнопки

Первая панель ленты — **LowLife**: кнопка с логотипом открывает окно «О программе» (версия расширения — коммит, из которого pyRevit его поставил, и ссылка на репозиторий; там же галочка «Показывать приветствие при запуске Revit», по умолчанию выключена), кнопка «Поиск» — найти любую кнопку LowLife по названию (или слову из подсказки) и сразу запустить её (Enter) или показать на ленте (Ctrl+Enter — откроет вкладку, и кнопка помигает оранжевой заливкой, даже если выбранная тема её скрывает), кнопка «Обратная связь» — сообщить автору о проблеме или предложить улучшение (выбор панели и кнопки + описание; сообщения уходят в Google Таблицу автора, [инструкция →](docs/feedback-panel.md)). LowLife также отправляет автору статистику запусков кнопок (какая кнопка, когда, кто — без содержимого моделей), чтобы было видно, что дорабатывать в первую очередь; выключается галочкой в окне «О программе». Вторая панель — **Мои панели**: кнопка «Создать мою панель» — соберите свои панели из нужных кнопок LowLife (с разных панелей, в своём порядке, перетаскиванием мышью) — они встанут на ленте сразу за ней и видны при любой теме; добавить кнопку можно и из «Поиска» («На мою панель»). На панели LowLife есть и выпадающий список «Тема» — он переключает, какие панели/кнопки видны на ленте — по дисциплине (СКС/СКУД/СОТ/СОУЭ/СПС/СПА/СС1), по группе (КНК — лотки, Электрические цепи, Настройки, Общее, Служебное) или «Моя панель» — только свои панели. У большинства рабочих кнопок есть Shift+клик — открывает настройки именно этой кнопки (единого окна настроек на панель нет). Подробнее о кнопках панели LowLife и темах — [docs/general-panels.md](docs/general-panels.md).

## Разработка

Общая библиотека лежит в `lib/` (пакет `lowlife`) и автоматически попадает в `sys.path` pyRevit — см. [lib/README.md](lib/README.md) для справки по модулям. Скрипты кнопок (`script.py`) должны оставаться тонкой оркестрацией поверх `lib/lowlife/`.

Билд-шага, пакетного менеджера и линтера нет; проверка изменений — через загрузку расширения в Revit. Чистая логика без Revit API (графы, адресация, шлейфы, раскладки) покрыта юнит-тестами в [tests/](tests/) — запуск `python -m pytest tests -v` под Python 2.7 + `pytest<5`, подробности в [tests/README.md](tests/README.md). Подробные архитектурные заметки и грабли IronPython/Revit API — в [CLAUDE.md](CLAUDE.md).

Иконки всех кнопок — в той же палитре, отдельно для светлой темы Revit (`icon.png`: светлый фон, чёрный рисунок) и для тёмной (`icon.dark.png`: чёрный фон, белый рисунок), с оранжевым акцентом (`docs/brand/restyle_icons.py`).
