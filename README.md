# LowLife

pyRevit-расширение для проектирования слаботочных систем (СКС, СКУД, СПС, СОУЭ, СПА) в Autodesk Revit: скрипты IronPython/CPython 2, запускаются внутри Revit через pyRevit.

## Установка

Добавьте расширение в pyRevit по ссылке на этот репозиторий (Extensions → Add from GitHub URL). pyRevit сам клонирует репозиторий в `%APPDATA%\pyRevit\Extensions\LowLife.extension\` — вкладка `LowLife.tab` должна оставаться в корне репозитория, отдельной папки-обёртки `.extension` в самом репозитории нет и быть не должно.

Обновление — повторный pull через менеджер расширений pyRevit и перезагрузка pyRevit / перезапуск Revit.

## Панели

- **SCS** — структурированная кабельная система: расстановка узлов трассы, адресация, синхронизация электрических цепей и длин.
- **SKUD** — система контроля и управления доступом.
- **SPS / SOUE / SPA** — пожарная сигнализация, оповещение и управление эвакуацией, автоматика пожаротушения: построение шлейфов/цепей по адресам, расчёт длин колец и стояков.
- **CircuitsSCS / CircuitsSKUD / CircuitsSPA / CircuitsSPS / CircuitsGeneric / CircuitsDelete** — построение и удаление электрических цепей для соответствующих дисциплин.
- **Tray*** (Ladder/Perforated/Roof/Unperforated/Wire), **ToolsTraySection** — семейства и заполнение кабельных лотков.
- **Tools / ToolsExport / ToolsFamilies / ToolsRooms / ToolsSchedules** — вспомогательные инструменты общего назначения: работа со спецификациями и Excel, экспорт листов, каталог семейств, поиск и марки помещений и т.п.
- **FilterSelection** — выбор элементов с фильтром по категориям.
- **SOT**, **Music** — дополнительные узкоспециализированные инструменты.
- **_Themes** — переключение цветовых тем панелей.

Подробности по конкретным инструментам — в [docs/](docs/) и в `README.md` внутри `lib/`, `tests/`, `csharp/FamilyCatalog`, `addins/FamilyVersionStamp`.

## Разработка

Общая библиотека лежит в `lib/` (пакет `lowlife`) и автоматически попадает в `sys.path` pyRevit — см. [lib/README.md](lib/README.md) для справки по модулям. Скрипты кнопок (`script.py`) должны оставаться тонкой оркестрацией поверх `lib/lowlife/`.

Билд-шага, пакетного менеджера и линтера нет; проверка изменений — через загрузку расширения в Revit. Подробные архитектурные заметки и грабли IronPython/Revit API — в [CLAUDE.md](CLAUDE.md).
